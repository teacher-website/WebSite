時鐘電路：會自己動的紅石 ⏰

讓燈自己一直閃、讓音符盒自己打拍子——只要把火把的輸出「繞一圈回到自己背後」，電路就會一直開、關、開、關。這叫時鐘電路。也用 MakeCode 做一個程式時鐘來比比看。

🧱 紅石火把、紅石中繼器、紅石粉、紅石燈、音符盒💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 知道時鐘電路＝輸出接回輸入（火把＋中繼器繞一圈）。

  3. 用 MakeCode 的「重複」與「暫停」做出程式時鐘。

📚 新元件小教室

⏰時鐘電路火把的電繞一圈回到自己背後 → 火把熄 → 電沒了 → 火把又亮 → ……一直重複。
⏩用中繼器調速度繞的路上中繼器的延遲越大，閃得越慢。
🔥火把會燒壞遊戲裡火把開關太快（1 秒內很多次）會「燒壞」暫時不亮，所以中繼器的延遲要調大一點（3～4）。

🔑 今天的重點

  • 時鐘電路一定要有「延遲」（中繼器），否則會快到燒壞火把。
  • 想讓時鐘停下來：在繞圈的路上加一個拉桿控制的地方，或直接拿掉一格紅石粉。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：閃爍警示燈 🚨

🎒 準備物品：紅石火把、石頭、紅石粉、紅石中繼器、紅石燈

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 放一顆石頭，在側面插紅石火把。
  2. 從火把鋪紅石粉，繞一圈（中間放 1～2 個中繼器，延遲調到 4）回到石頭旁邊，接進石頭。
  3. 在繞圈的線旁邊放一盞紅石燈。
  4. 燈開始自己閃！數一數 10 秒閃幾次。
💡 中繼器的箭頭方向要順著繞圈的方向，方向錯了電就繞不回來；延遲至少調到 3，太快火把會燒壞。
🐣 三、四年級：網頁補上中繼器，在遊戲裡蓋出會閃的燈。
🦊 五、六年級：加一個拉桿，讓警示燈可以「開始／停止」。

🎮 應用 2：音符盒節拍器 🥁

🎒 準備物品：時鐘電路、音符盒

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 在時鐘電路旁邊放一個音符盒。
  2. 每次電路「開」，音符盒就響一聲。
  3. 調整中繼器延遲，找出「一秒一拍」的設定。
  4. 🦊 接 2 個不同樂器的音符盒（下面墊不同方塊），做出「咚、喳」的節奏。
💡 音符盒下面墊石頭是低音鼓、墊沙子是小鼓、墊玻璃是喀喀聲。
🐣 三、四年級：做出會打拍子的節拍器。
🦊 五、六年級：做出兩種樂器的節奏。

💻 MakeCode：程式時鐘：讓燈閃 N 次

程式用「重複」加上「暫停」就能做出時鐘，而且可以精準決定閃幾次、每次多久。紅石時鐘和程式時鐘各有好處。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"blink"} 參數 {num1}
  loops: 重複 {num1} 次
    blocks: 放置 [紅石方塊] 位於 {~0 ~0 ~2}
    loops: 暫停 {500} 毫秒
    blocks: 放置 [空氣] 位於 {~0 ~0 ~2}
    loops: 暫停 {500} 毫秒
JavaScript
player.onChat("blink", function (num1) {
    for (let index = 0; index < num1; index++) {
        blocks.place(REDSTONE_BLOCK, pos(0, 0, 2))
        loops.pause(500)
        blocks.place(AIR, pos(0, 0, 2))
        loops.pause(500)
    }
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 在面前 2 格的旁邊放一盞紅石燈（程式放紅石方塊時燈就亮）。
  2. 輸入 blink 10：燈閃 10 次，每次 1 秒。
  3. 把 500 改成 100 或 2000，閃爍速度有什麼變化？
  4. 討論：紅石時鐘和程式時鐘，哪一個可以「閃剛好 10 次」？
📌 暫停的單位是毫秒（1000 毫秒 = 1 秒）。

👩‍🏫 教師備註
  • 「走一步」按鈕可以讓學生看清楚每 0.1 秒訊號跑到哪裡，非常適合解釋時鐘。
  • 時鐘電路會一直產生聲音（音符盒），建議戴耳機或降低音量；下課前請學生把時鐘停掉。
  • 基岩版另一種常見時鐘：兩個漏斗互相傳物品＋比較器（漏斗時鐘），🦊 可以上網查「漏斗時鐘 基岩版」挑戰。
