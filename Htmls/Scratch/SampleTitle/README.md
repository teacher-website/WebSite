# 貓咪甜點店：片頭與選單

> 建立日期：2026-09-24　·　對象：國小高年級　·　狀態：**範例 .sb3＋互動教學網頁，已完成**
> 主題：Scratch 作品的「門面」——片頭動畫、故事簡介、遊戲說明、主選單、遊戲標題畫面

## 一、這個專案是什麼

一份可以直接接上自己遊戲的**選單系統範本**，做成一間貓咪甜點店：

```
片頭（招牌落下・店名放大・貓店長登場）
   ↓ 可跳過
故事簡介（打字機效果）
   ↓ 可跳過
遊戲說明（三頁輪播）
   ↓ 可跳過
主選單 ──→ 遊戲一／遊戲二／遊戲三 標題畫面 ──→ 回選單
   └── 重看片頭・看故事・看說明（看完會回到選單）
```

遊戲畫面目前**只有標題**，就是留給學生把自己的遊戲接上去的位置。

## 二、教材要教的三件事

| 重點 | 內容 |
|---|---|
| **① 用一個變數管理所有畫面** | 變數 `畫面` ＋ 一個訊息 `切換畫面`；每個角色只問「現在是我的畫面嗎？」。加新畫面不用改舊角色。 |
| **② 每個段落都能跳過** | 自訂積木「**等 n 秒（可跳過）**」取代內建的「等待 n 秒」；跳過鈕只負責把 `跳過` 設成 1。 |
| **③ 動畫要有彈性** | 招牌「衝過頭再彈回來」、店名「一邊放大一邊淡入」、按鈕「慢慢脹大」；每個效果都給**入門／進階**兩種做法。 |

## 四、規格一覽

| 項目 | 內容 |
|---|---|
| 擴充功能 | **不需要**（純 Scratch 內建積木） |
| 角色 | 14 個：小裝飾、招牌、店名、副標、說明卡、選單標題、草莓蛋糕、布丁、馬卡龍、小按鈕、遊戲標題、回選單鈕、跳過鈕、貓店長 |
| 背景 | 2 個：店內、遊戲畫面 |
| 積木總數 | 588 |
| 主要變數 | `畫面`、`跳過`、`回到哪`、`目前遊戲`、`等到`、`說明頁` |
| 自訂積木 | 舞台：等 n 秒（可跳過）、切到 ◯、播完了接著去 ◯、播片頭、播故事、播說明；貓店長：打字 ◯、等 n 秒（可跳過） |
| 跳過方式 | 畫面右下角的跳過鈕，或**空白鍵** |
| 音效 | 開店鈴、按鈕、翻頁、打字、登場、咚（皆為合成波形） |

## 五、驗證

以 scratch-vm 載入範例，模擬滑鼠點擊把每一條路徑都走過：

- **主線**：片頭 →（按跳過）→ 故事 →（跳過）→ 說明 →（跳過）→ 選單，每一段都正確銜接。
- **片頭動畫**：招牌最後停在 y ＝ 76、店名尺寸回到 100（被跳過時也一樣）。
- **選單**：三個甜點、選單標題、三顆小按鈕都顯示；跳過鈕與招牌正確隱藏。
- **小按鈕位置**：x ＝ 編號 × 160 − 320 → −160／0／160，三顆都在畫面內。
- **遊戲畫面**：點草莓蛋糕／布丁／馬卡龍 → `目前遊戲` ＝ 1／2／3、標題造型正確、背景換成遊戲畫面、貓店長正確隱藏；按回選單都回得來。
- **回頭看**：從選單按「重看片頭」「看故事」「看說明」，播完都會**回到選單**（`回到哪` 機制），不會繼續往下一頁跑。
- **空白鍵**：同樣可以跳過。
- **分身**：小裝飾會自己刪除，不會累積。
- **網頁**：Chromium 檢查，18 段積木圖全部正常渲染、三個實驗室無錯誤；試玩台的流程與 .sb3 完全一致。

## 六、實作時修正的問題

1. **小按鈕的位置公式算錯**：原本寫成 `編號 × 160 − 160`，第 3 顆跑到 x ＝ 320（畫面外）。
   正確是 `編號 × 160 − 320`。教材也加上「把第 1 顆和第 3 顆代進去檢查一次」的提醒。
2. **故事段落中有不能跳過的等待**：貓店長三句話之間原本用內建的「等待 n 秒」，
   按了跳過還要等 1.4 秒才會換頁。改成在貓店長角色裡也做一塊「等 n 秒（可跳過）」——
   這也變成教材裡的一個重點：**自訂積木只屬於自己的角色**。

## 七、延伸方向

- 在遊戲標題畫面加「如果 `目前遊戲` ＝ 1 → 廣播 開始遊戲一」，把學生自己的遊戲接上去。
- 多加一個「設定」畫面（音量、難度），體會新增畫面有多簡單。
- 把主題換成自己的（校園、太空、海底），只要換造型與文字，程式完全不用動。
