# Scratch 積木教室（基礎積木互動教材）

> 建立日期：2026-09-15　·　對象：國小中高年級　·　狀態：**第一～四期全部完成**
> （八大類共 115 塊積木、單元 1～7、易錯點總表、七張紙本學習單、紙本評量）

## 一、這個專案是什麼

把 Scratch 3 的基礎積木做成互動教材。核心特色是一個**迷你舞台模擬器**：
每一塊積木都能直接修改參數並按「試一試」，角色會在網頁裡真的動給學生看，
不必先開 Scratch 也能理解積木在做什麼。

採**雙層架構**：
- **積木圖鑑**（`guide.html`）：依類別查積木、搜尋、任務導向索引，每塊可試玩，也能串成小腳本執行。
- **分課實作單**（`unit*.html`）：依教學進度分單元，各有學生版與教師版。

## 四、怎麼新增積木（最重要的一節）

### 步驟 1：在 `assets/blocks.js` 的 `BLOCKS` 陣列加一筆

```js
{
  id:'move',                       // 唯一代號，也是卡片的 DOM id（card-move）
  cat:'motion',                    // 類別：motion/looks/sound/events/control/sensing/operators/variables/myblocks
  shape:'stack',                   // stack 堆疊 / round 回報 / hat 帽子 / cap 結束 / c C型 / c2 C型含否則
  op:'move',                       // 對應 stage.js 裡 RUN 的函式名稱
  chk:true,                        // （選填）回報型積木左側的勾選框
  parts:[                          // 積木上的零件，由左到右
    {t:'txt', v:'移動'},                                  // 純文字
    {t:'ico', v:'↻'},                                    // 圖示
    {t:'num', k:'STEPS', v:10},                          // 數字輸入（k 是參數名）
    {t:'str', k:'MSG', v:'Hello!'},                      // 文字輸入
    {t:'drop',k:'TO', v:'隨機', opts:['隨機','鼠標']},     // 下拉選單
    {t:'clr', k:'C', v:'綠色（草叢）', opts:[...]},         // 顏色選單（外觀同下拉）
    {t:'cond',k:'COND', v:'碰到邊緣'},                     // 六角形槽（附預設條件下拉）
    {t:'bool',k:'A'}                                     // 六角形空槽（且／或／不成立用）
  ],
  // num / str 可加 narrow:true（窄欄位）或 wide:true（寬欄位）
  parts2:[{t:'txt',v:'否則'}],     // 只有 shape:'c2' 需要（第二個凹槽的標頭）
  desc:'…',   // 白話說明（可用 <b>）
  use:'…',    // 什麼時候用
  miss:'…',   // 容易搞混（學生迷思）
  rel:['turnright','pointdir']     // 相關積木（會變成可點按鈕）
}
```

### 步驟 2：在 `assets/stage.js` 的 `RUN` 物件加上對應函式

```js
move:function(a){ /* a.STEPS 就是使用者輸入的值 */ render(); },
```
- 需要動畫的積木（例如滑行）回傳 **Promise**，腳本執行時會自動等待。
- 回傳**字串**會顯示在「試一試」旁邊當作提示。

### 步驟 3：開放類別與任務索引

- `BLOCK_CATS` 裡把該類別的 `ready` 改成 `true`，頂部標籤就會可以點。
- `TASKS` 陣列加上 `{cat:'control', label:'我想讓程式重複做', ids:[...]}`。

改完**不必動任何 HTML**，圖鑑與單元頁會自動同步。

## 五、模擬器（stage.js）現況

**舞台座標**：x −240~240（右為正）、y −180~180（上為正）；**角度**：0 上、90 右、180 下、−90 左。

**已支援**：動作類全部、外觀類的說話／想著（含泡泡樣式差異與自動消失）、
兩個造型、三張背景、尺寸、顯示隱藏、圖層（舞台上有一叢草當道具可看出前後）、
圖像效果的**顏色／亮度／幻影**、等待、廣播橫幅、分身（半透明靜態複製品）。

**執行引擎（ui.js）**：`UI.Builder` 提供可編輯的巢狀腳本區（C 型積木可放入其他積木），
`UI.script` 產生唯讀的示範腳本；兩者都由同一個直譯器執行，支援
**重複 N 次／重複無限次／重複直到／如果…那麼／如果…否則／等待直到／停止**，
執行時逐塊高亮並顯示迴圈圈數，可調速度（慢／中／快），無限迴圈上限 2000 圈。

**條件（六角形槽）**：`{t:'cond'}` 附四個內建條件下拉（碰到邊緣、角色在右半邊、
角色在上半邊、按下空白鍵，見 `Stage.cond(name)`），也可以被真正的布林積木取代。

**嵌套（積木放進積木）**：欄位的值可以是**字面值**，也可以是節點物件
`{__b:'積木id', args:{...}}`。`UI.evalSync()` 會遞迴求值，
回報型／布林型積木一律用 **`Stage.calc(op,args)`（同步）** 取值，
所以迴圈條件每一圈都能重新計算。互動方式是**兩段式點選**：
`UI.startFill(block,args)` 進入填空模式 → 腳本裡相容的欄位加上 `.slot.pick` 發亮 →
點一下寫進 `args[k]` → 欄位右上角的 `.popx` 可再取出。
圖鑑卡片上，`shape` 為 `round`／`bool` 的積木按鈕會自動變成「⤵ 放進欄位」。

**變數**：`blocks.js` 的 `VAR_NAMES` 定義小舞台預設提供的四個變數
（`my variable`／分數／生命／速度）。真實 Scratch 要自己按「建立一個變數」，且**每個變數各有一塊圓形積木**；
小舞台為了節省版面，把回報積木做成下拉選單（已在圖鑑的「容易搞混」裡說明）。
`S.vars` 存值、`S.varShow` 存是否顯示，`drawMonitors()` 會在舞台左上角畫出
和真實 Scratch 一樣的橙色數值方塊。`Stage.reset()` 會把四個變數歸零。

**清單**：`LIST_NAMES` 定義預設清單（排行榜／我的清單）。清單積木在 Scratch 裡屬於**變數分類**，
顏色是比變數深一點的橘（`tone:'list'` → CSS 的 `.listtone`）。`S.lists` 存陣列、`S.listShow` 存是否顯示，
`drawLists()` 在舞台**右上角**畫監看器（編號＋橙色內容膠囊＋長度，超過 6 項只顯示前 6 項）。
索引一律**從 1 開始**，取超過範圍回傳空字串。

**函式積木（自訂積木）**：`MY_NAMES` 定義預設的自訂積木名稱。
真實 Scratch 的「定義」是**帽子積木**、要做的事接在下面；本專案的 Builder 是扁平串列，
因此把「定義」做成 **C 型積木**（CSS 再把 `.cwrap.myblocks .chead` 的上緣改成帽子的圓角），
語意才正確——這點已寫在該積木的「容易搞混」與教師說明裡。
執行時 `runScript` 會把最外層的節點存進 `ROOT`，`callmy` 依 `NAME` 找同層的 `define` 並執行它的 body；
`callarg` 會把引數推進 `ARGS` 堆疊，定義裡的 `argval` 由 `evalSync` 直接取堆疊頂端，
呼叫結束再彈出。遞迴深度上限 12 層。

> 單元 6、7 的示範腳本是目前**嵌套最深**的例子，改引擎時請拿它們回歸測試：
> 單元 6 的走訪是「說出 ← 清單第幾項 ← 變數」三層；
> 單元 7 的帶參數作品會驗證 `ARGS` 堆疊（走 20＋60＋120，角色剛好從 −200 走到 0）。

**對外 API**：`Stage.init(svg)`、`Stage.run(op,args)→Promise`、`Stage.reset()`、
`Stage.onChange(fn)`、`Stage.state`、`Stage.setGrid/setArrow/setMouseMark`、
`Stage.setTarget(x,y)/clearTarget()/distToTarget()`（單元 1 的座標測驗用）。

**與真實 Scratch 的差異（已在教材中說明）**：
- 角色**不會跑出舞台**（真實 Scratch 允許部分超出）。
- 圖像效果的**魚眼、漩渦、像素化、馬賽克不模擬**——這四種需逐像素運算，向量角色要先轉點陣、
  每幀重算，複雜度高且在老舊校用電腦上會拖慢畫面，教學價值也較低。按下去會顯示提示並記錄數值。
- 「圖層上移 N 層」簡化為「往上＝到前面、往下＝到後面」（舞台只有一個道具）。
- 角色是**原創繪製**的小獸，未使用 Scratch 官方吉祥物。
- **碰到什麼**只提供鼠標／邊緣／草叢（道具）三個目標（舞台只有一個角色）。
- **碰到顏色**改為四個現成顏色並以區域判斷模擬（真實 Scratch 是滴管吸色）。
- **聲音響度**沒有麥克風，回傳會緩慢起伏的**模擬數值**；**用戶名稱**回傳固定說明文字。
- **拖曳方式**只記錄設定值。**詢問並等待**用 SVG `foreignObject` 放一個真的輸入框，行為與 Scratch 一致。
- 嵌套操作是**兩段式點選**而非拖曳（觸控與投影教學較穩定），概念相同。

**單元 6 一次記住很多件事**：清單實驗室（可自行輸入內容，七個按鈕操作排行榜，旁邊同步列出編號表）、
12 塊積木試玩、**「添加 vs 插入」左右對照**、走訪整張清單的**三層嵌套**示範
（說出 ← 第幾項 ← 編號變數）、三個作品（點名冊、查名次、逐項唸出）。

**單元 7 把程式包起來重複用**：**「貼三次 vs 定義一次」左右對照**（附「要改幾個地方」的提問）、
建立自訂積木的三個步驟、5 塊積木試玩、帶參數的示範（同一塊積木走 20／60／120）、
三個作品（跳一下、走正方形、走幾步）。

**紙本學習單**（`worksheet.html`）：七個單元各一張 **A4**，內容是本課積木圖、兩題紙筆練習、
「我的設計」空白區與自我檢核，另有班級姓名欄與老師簽章欄。上方可勾選要列印哪幾張。
列印時「我的設計」會**自動撐滿剩下的版面**，所以每一張都剛好一頁。

**紙本評量**（`assess.html`）：100 分總結測驗，涵蓋單元 1～7。
選擇題 10 題 40 分、看積木回答 5 題 30 分、找出錯誤 3 題 18 分、簡答 2 題 12 分。
**解答與評分重點可一鍵收合**，收合後列印就是學生考卷，展開列印就是教師卷。

> 兩份紙本教材的積木都是**用 `UI.blockEl` 即時畫出來的真實積木圖**，不是截圖，
> 所以改了 `blocks.js` 的用詞，考卷和學習單會自動跟著更新。
> 列印時 `print-color-adjust:exact` 會保留積木顏色。

**七份教師手冊**：教學目標、40 分鐘節次流程、**關鍵概念與學生迷思對照表**、
各作品教學提示與易錯點、差異化與不插電替代方案、三向度評量規準表。可列印。
