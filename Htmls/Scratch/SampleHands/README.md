# 手勢辨識大挑戰（數字 0～4 ＋ 剪刀石頭布）

用 **Handpose2Scratch** 做的兩種手勢判斷教學，含可執行的 `.sb3` 範例與互動式學習網頁。

## 這個專案在教什麼

同一套偵測，做出兩種不同的判斷：

| | 問的問題 | 用到的資料 |
|---|---|---|
| **① 數字關** | 幾根手指伸直？ | `手指數`（四根相加） |
| **② 猜拳關** | 是哪幾根手指伸直？ | `指型`（四位密碼 0000／1100／1111） |

核心判斷只有一句話，**只用到「比大小」和「加法」**：

> 指尖的 y 座標 **＞** 同一根手指第二關節的 y 座標　→　這根手指伸直了

不需要平方根或角度，手離鏡頭遠近、左右鏡像都不影響結果 —— 這是它適合國小課堂的原因。

實際要在教室裡穩定運作，還加上四道保險（教學第 5 章有實測數字）：

1. **守門 ①**　手腕 x > −250 —— 偵測不到手時座標積木回傳空字串
2. **守門 ②**　中指第三關節 y > 手腕 y —— 確認手有立起來
3. **每根手指的餘裕（遲滯）**　餘裕 ＝ 手長 × 0.08，要超過才改變狀態，中間維持原狀
4. **整組手勢的穩定時間**　同一個指型維持 0.15 秒以上才寫進「確定」變數
5. **掉格容忍**　連續 0.4 秒抓不到手才清空 —— 少了這一道，攝影機偶爾漏一格就會讓玩家覺得毫無反應

## 怎麼用

1. 用瀏覽器打開 `index.html`。
2. 範例檔請用 **stretch3.github.io** 開啟，左下角「添加擴展」選 **Handpose2Scratch**，允許使用攝影機後點綠旗。
3. 沒有攝影機也能上課：按 **K** 切換鍵盤模式，之後按 **0～4** 就等於比出手勢。

### 鍵盤快速鍵

| 鍵 | 作用 |
|---|---|
| `1` / `2` | 在選單時直接進入數字關 / 猜拳關 |
| `M` | 回選單 |
| `D` | 開關骨架點 |
| `K` | 切換鍵盤模式 |
| `0`～`4` | 鍵盤模式下代替手勢 |

## 教學設計重點

- **第 2 章**：為什麼是「指尖 vs 同一根手指的關節」，而不是絕對座標、指尖距離或角度。
- **第 4 章**：讓學生自己發現「數字 2」和「剪刀」都是兩根 —— 數量不夠用，要看指型。
- **第 5 章**：四道保險與實測數字。兩個關鍵觀念：
  防抖動要用**計時器**（維持 0.15 秒）而不是次數 —— Scratch 的 `重複無限次`
  若內容只有變數運算，一個畫面更新內會跑好幾百次，「連續 5 次」等於沒有防到；
  以及**抓不到手時不要馬上清空**，否則手指燈是對的、遊戲卻怎麼都不認。
- **第 7 章**：出題要避開玩家**現在**比的數字，否則會一出題就自動答對。
- **第 8 章**：猜拳勝負可以用一個餘數算式取代三條規則 ——
  `（我的編號 ÷ 3 的餘數）＋ 1 ＝ 對方編號 → 我贏`（1 石頭、2 剪刀、3 布）。

## 驗證紀錄

範例檔以 headless `scratch-vm` 實際載入執行，通過下列測試：

- 16 種手指組合的 `手指數` / `指型` / `猜拳號` 全部正確
- 偵測不到手、手橫放 → 守門成立（`看得到手 = 0`）
- 掉一格（0.25 秒）→ `確定手指數` 不被清掉；真的離開 0.95 秒 → 歸零、手指燈熄滅
- 同一手勢在三種遠近位置 → 指型一致
- 高速抖動（每 60 ms 換一次）→ `確定指型` 不跟著跳
- **雜訊測試**（每 33 ms 送一組帶雜訊的假座標）：
  雜訊 ±5 px、彎曲指尖僅低於關節 4 px、掉格率 0～20% 的各種組合下，
  `確定手指數` 正確的時間比例皆為 **100%**（修正前為 0～64%）
- **換手勢測試**：連續 10 個手勢，在雜訊 ±6 px、掉格率 15% 下全部認出，
  反應時間中位數 **190 ms**、最慢 289 ms
- 數字關：全部答對得 8 分；完全不動則 8 題都時間到、得 0 分；出題不連續重複
- 猜拳關：15 回合的勝負判定與餘數算式完全一致；分數等於贏的次數
- 猜拳關：一直比看不懂的手勢 → 回合不計，連續 6 次自動回選單
- 關卡中按 M → 回選單且關卡程式確實停止
- 教學網頁：四個互動實驗室與試玩台皆無 JavaScript 例外

## 變更紀錄

- **2026-09-24（第二版）**　修正「手指燈是對的，遊戲卻判定不到」的問題。
  用帶雜訊的假座標重現後找到兩個原因：
  1. 攝影機偶爾掉一格就把 `確定手指數` 清成 −1 並重置穩定計時 →
     只要每 20 格掉 1 格，正確率就從 100% 掉到 61～64%。
     改成連續 0.4 秒抓不到才清空（新增自訂積木「清空手勢」）。
  2. 彎曲手指的指尖離第二關節太近，雜訊一來就在 0／1 之間跳（每秒 19 次），
     0.2 秒的穩定窗永遠湊不滿 → 正確率只有 17%。
     改成每根手指加上遲滯（餘裕 ＝ 手長 × 0.08）。
  同時把穩定門檻從 0.2 秒降到 0.15 秒、監看器加上 `確定手指數`。
  修正後在所有測試條件下正確率皆為 100%，換手勢反應時間中位數 190 ms。
  積木數 731 → 803。教學第 3、5 章與程式說明文件同步更新，
  第 5 章的互動實驗室改成三條軌跡（只比大小／加餘裕／再加穩定時間）。
