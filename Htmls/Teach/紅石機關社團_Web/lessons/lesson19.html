專題：設計我們的密室逃脫 🗝️

最後兩堂是專題！2～3 人一組，用 18 堂學到的紅石機關設計一間「密室逃脫」：至少 3 個機關、1 個邏輯謎題。今天完成設計圖並開始建造，下週互相闖關！

🧱 全部元件、告示牌、書與筆、NPC（選用）、MakeCode（選用）💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 和組員一起完成密室逃脫設計單。
  2. 在網頁紅石實驗室先試做最難的機關。
  3. 開始在遊戲中建造，至少完成 2 個機關。

📚 新元件小教室

📋密室逃脫的要素故事（為什麼被關在這裡）＋線索（告示牌、書）＋機關（解開才能前進）＋出口。
🧩好謎題的秘訣線索要藏得到、也找得到。答案要能從線索推出來，不是亂猜。
🛠️可以用的機關密碼鎖、隱藏門、壓力板陷阱、XOR 答題機、聲控門、講台翻頁、射箭開門、音樂解謎……

🔑 今天的重點

  • 至少 3 個不同的紅石機關，其中 1 個要用到邏輯（AND／OR／XOR／NOT／密碼鎖）。
  • 在出口放一個「完成」按鈕：按下去放煙火或播音樂。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 第 1 節：設計單 📝

🎒 準備物品：設計單（下面可以直接填，會存在這台電腦）

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 想一個故事：例如「被困在紅石博士的實驗室」。
  2. 畫出房間配置：幾個房間？玩家從哪裡進、從哪裡出？
  3. 每個房間放一個機關，寫下「怎麼解開」。
  4. 在網頁的紅石實驗室試做最難的那一個。
💡 設計不用太大：3 個 5×5 的房間就夠了。
🐣 三、四年級：3 個機關，各自獨立。
🦊 五、六年級：機關之間有關聯：第 1 關的答案是第 2 關的線索。

🎮 第 2 節：開始建造 🧱

🎒 準備物品：全部元件

🧱 在遊戲裡做

  1. 先蓋房間外牆和出入口。
  2. 從「最難的機關」開始做，做好就測試。
  3. 放告示牌寫線索、書與筆寫故事。
  4. 每完成一個機關，在設計單上打勾。
💡 每做完一個機關就請組員「假裝不知道答案」試玩一次。
🐣 三、四年級：完成 2 個機關。
🦊 五、六年級：完成 3 個機關＋MakeCode 開場（選用）。

💻 MakeCode：（選用）密室開場與倒數計時

用程式做「開場故事」和「倒數計時」，讓密室更像真的遊戲。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"start"}
  player: 說 {"歡迎來到紅石博士的實驗室！你有 5 分鐘逃出去！"}
  loops: 重複 {5} 次
    loops: 暫停 {60000} 毫秒
    player: 說 {"又過了 1 分鐘…"}
  player: 說 {"時間到！"}
JavaScript
player.onChat("start", function () {
    player.say("歡迎來到紅石博士的實驗室！你有 5 分鐘逃出去！")
    for (let index = 0; index < 5; index++) {
        loops.pause(60000)
        player.say("又過了 1 分鐘…")
    }
    player.say("時間到！")
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 把故事改成自己組的版本。
  2. 闖關的人開始前輸入 start。
  3. 60000 毫秒 = 1 分鐘；想改成 3 分鐘就把重複次數改成 3。
  4. 🦊 也可以用 Minecraft Education 的 NPC 放在入口講故事。
📌 程式是選用的；沒有用 MakeCode 也可以用告示牌和書說故事。
