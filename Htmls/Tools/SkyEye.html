天眼・書籤版

零安裝。點一下書籤，就能把這個網站上討厭的東西點掉。

把下面這顆按鈕拖到書籤列

桌機請直接拖曳；手機請看下面的「手機怎麼裝」。

👁 天眼

內嵌版・43.5 KB・整包程式都在書籤裡，不連任何伺服器。

怎麼用

  1. 在任何網站上點一下「天眼」書籤，畫面下方會出現控制面板。
  2. 按 開啟天眼・選取元件，然後點掉你不想看到的東西。
    點錯了按「↑ 上一層」擴大範圍，被面板擋住就按「⇅ 換邊」。
  3. 選好動作（隱藏／移除／解除固定／解除遮罩），按 存檔。
  4. 下次來到這個網站，再點一次書籤，剛才移除的東西就會自動消失。

先說清楚它的極限

書籤版沒辦法在頁面載入時自動執行——瀏覽器不允許一個書籤自己跑起來。所以：

狀況書籤版擴充功能版
每次開網頁自動套用要手動點書籤自動
規則存在哪該網站自己的 localStorage瀏覽器的擴充功能儲存區
清除瀏覽資料規則會一起被清掉不受影響
子網域共用規則不共用（m. 與 www. 各自獨立）共用
嚴格 CSP 的網站可能整個跑不起來正常
AI 幫忙只有本地啟發式本地＋可選 Claude API
安裝拖一下就好要載入擴充功能

會長期用的網站建議裝擴充功能版；書籤版適合臨時、借用別人的電腦，或不方便裝擴充功能的環境。

手機怎麼裝

iPhone / iPad（Safari）

  1. 先按下面的「複製書籤程式碼」。
  2. 在 Safari 隨便開一個網頁，按分享 → 加入書籤，名稱打「天眼」，儲存。
  3. 開啟書籤列表 → 編輯 → 點剛才那個書籤 → 把網址整段刪掉，貼上剛才複製的內容 → 完成。

Android（Chrome）

  1. 按「複製書籤程式碼」。
  2. 先把任意網頁加入書籤。
  3. 到書籤管理頁編輯它，名稱改成「天眼」，網址換成剛才複製的內容。
  4. 之後在網址列打「天眼」，選那個書籤就會執行。

Loader 版（給有自己網站空間的人）

書籤只放一行載入器，程式碼放在你自己的網址上。好處是之後改版不用重設每台裝置的書籤； 代價是有些網站的 CSP 會擋掉外部腳本，這時請改用上面的內嵌版。

  1. 把 tianyan.js 上傳到任何靜態空間（GitHub Pages、Cloudflare Pages 都行）。
  2. 把下面欄位裡的 __URL__ 換成那個檔案的完整網址。
  3. 拖曳產生出來的按鈕，或複製內容自行建立書籤。
👁 天眼（loader）

隱私

書籤版不連任何伺服器，沒有遙測，沒有帳號。規則存在你正在瀏覽的那個網站自己的 localStorage 裡，只有那個網站的分頁讀得到，也只存在這台裝置上。

「請 AI 幫忙」在書籤版只用內建的離線啟發式規則，不會送出任何資料—— 要用雲端模型請改用擴充功能版，因為把 API 金鑰放進任意網站的 localStorage 並不安全。
