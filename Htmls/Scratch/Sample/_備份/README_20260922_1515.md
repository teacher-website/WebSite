# 爆炸頭節奏大師・Handpose2Scratch 節奏遊戲教學

> 建立日期：2026-09-21　·　對象：國小高年級　·　狀態：**學生教學＋試玩＋範例 .sb3＋教師手冊，已完成**

## 一、這個專案是什麼

仿照 Bishi Bashi Special（Hyper）的 **Perm Mania**：師傅先示範 8 拍節奏，玩家照著做，一整段最多錯 1 次就過關，爆炸頭變大。
改用 **Handpose2Scratch** 手勢操作：食指指 **左／上／右** 出招，**握拳** 是預備姿勢（每次出招後都要回到拳）。

## 三、核心設計（修改時請保持一致）

| 項目 | 設定 |
|---|---|
| 手勢規則 | 手掌＝距離(1,10)；中指長(10,13) > 手掌×門檻 → 其他；食指長(6,9) < 手掌×門檻 → 拳；否則 \|dx\|>\|dy\| 判左右，dy>0 為上 |
| 出招 | 「上膛」：看到拳 → 上膛=1；上膛=1 且看到方向 → 廣播「出招」、上膛=0 |
| 譜面 | 8 個字，左／上／右／-（休息），共 5 關 |
| 節拍 | 用計時器：第 n 拍＝開始時間＋(n−1)×拍長；拍長 0.8 秒 |
| 判定 | 時間差 < 容許(0.3) → 方向對 GOOD、錯 BAD；亂出招 BAD；過時未出招 MISS；延遲補償 0.15 秒 |
| 過關 | 錯誤 < 2；爆炸頭尺寸＝40＋分數×20 |
| 方向 | 攝影機選「開啟（on）」＝鏡像；往右指 dx 為正（教學第 2 章有方向測試） |

## 四、驗證

- 範例 .sb3 以 scratch-vm 載入，搭配模擬的 Handpose2Scratch 手部資料實際執行：
  六種手勢辨識正確；全部跟對 5 分、每回合漏 1 拍 5 分、方向全錯 0 分、鍵盤操作 5 分，皆跑完 5 回合。
- 網頁以 Chromium 截圖檢查桌機與手機寬度，無水平捲動、無程式錯誤。
- **尚未在實體攝影機上測試**：第一次上課前請在教室電腦試跑，必要時調整門檻、容許、延遲補償。

## 五、已知限制

- play.html 的攝影機模式需要網路（從 jsdelivr 載入 MediaPipe 0.10.21、從 Google 載入手部模型）；沒有網路時可用鍵盤模式。
- Handpose2Scratch 在不同版本的中文選單名稱可能不同，教材以「方向測試」為準，不依賴選單名稱。
- 字型透過 Google Fonts 載入，離線時退回系統字型。
