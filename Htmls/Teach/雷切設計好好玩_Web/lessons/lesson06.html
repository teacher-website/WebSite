📚 魔法小教室

⬜節點線經過的點；方形是尖角、圓形是平滑。
🔵控制把手拉長＝彎得多；轉方向＝改變彎的方向。
🖊️貝茲（鋼筆）B一點一點畫出線條，回到起點變成封閉形狀。
➕新增節點在線上點兩下。
🗑️刪除節點選節點按 Delete，形狀會變得更平滑。
🔒封閉路徑起點和終點接起來，才是一塊可以切下來的形狀。

🔑 今天的重點

  • 雷射切下來的形狀一定要「封閉」。
  • 節點越少，線條越順；用「簡化」可以減少節點。
  • 描圖時把圖片放最下層、鎖起來，畫完記得刪掉圖片。

🛠️ 動手做

每完成一個步驟，點一下打勾 ✓（會記在這台電腦）。

🛠️ 任務 1：捏捏看：水滴和魚

🎒 準備：Inkscape
  1. 畫一個圓，按 Shift＋Ctrl＋C 轉成路徑。
  2. 按 N，選最上面的節點往上拉 → 水滴。
  3. 按 Shift＋C 把它變成尖角。
  4. 在右邊的線上點兩下新增節點，往外拉出魚尾巴。

🛠️ 任務 2：動物剪影吊飾

🎒 準備：Inkscape、老師提供的動物剪影圖
  1. Ctrl＋I 匯入動物剪影圖，在「物件」選單鎖定它。
  2. 按 B 沿著輪廓點；彎的地方按住拖曳。
  3. 回到起點點一下，形狀就封閉了。
  4. 按 N 微調；節點太多就按 Ctrl＋L。
  5. 刪掉圖片，加掛孔（差集），改成紅色邊框、無填色。
  6. 存檔「第06堂_動物.svg」。
🐣 三、四年級：用節點工具把圓形改造成水滴、魚或葉子。
🦊 五、六年級：用鋼筆描出完整的動物剪影，加上雕刻的眼睛和花紋。
