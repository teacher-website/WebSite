# 互動學習網

學生用的課程互動學習網站：課本＋習作重點整理、互動實驗、隨堂練習與單元挑戰。

## 資料夾結構

```
互動學習網/                         ← 最上層入口（網站索引會顯示成一張卡片）
├── index.html                      ← 入口頁：列出所有科目（依 catalog.js 自動產生）
├── README.md
├── assets/                         ← 全站共用，所有科目、單元都引用這裡
│   ├── catalog.js                  ← ★ 課程目錄：科目與單元清單（唯一需要登記的地方）
│   ├── hub.css                     ← 全站樣式（日式可愛風）
│   ├── hub.js                      ← 入口頁／科目頁產生器、學習進度工具
│   └── lesson.js                   ← 單元頁引擎：分頁、內容區塊、題目批改、進度
├── 自然五上/                        ← 科目資料夾（名稱＝科目＋年級＋學期）
│   ├── index.html                  ← 科目頁：列出單元（只需改 data-subject）
│   └── 單元1_太陽的祕密/            ← 單元資料夾（名稱＝單元編號_單元名稱）
│       ├── index.html              ← 單元頁外殼（固定格式，複製即可）
│       ├── data.js                 ← ★ 本單元所有教材內容與題目
│       └── widgets.js              ← 本單元專屬的互動實驗元件
├── 社會五上/                        ← （之後新增）
└── ...
```

## 單元頁的分頁結構

每個單元統一為以下分頁（可依單元增減）：

1. 🧭 單元導覽：我學過了／現在要學、單元架構
2. 各小節（例如 1-1、1-2、1-3）：課本活動重點、互動實驗、充電站、安全叮嚀、習作練習、隨堂小測驗
3. 📝 單元總整理：圖解筆記、習作重點填空、名詞字卡
4. 📖 科學樂讀（或其他延伸閱讀）
5. 🏆 單元挑戰：整份交卷計分

每個區塊都標註「課本 p.○」「習作 p.○」出處，方便對照紙本。

## 新增一個單元（例：自然五上 單元2）

1. 複製 `自然五上/單元1_太陽的祕密/` 成 `自然五上/單元2_千變萬化的植物/`
2. 改寫新資料夾中的 `data.js`（`id` 改成 `sci5a-u2`、`no: 2`、`title` 與各分頁內容）
3. 需要新的互動實驗就寫在該單元的 `widgets.js`；不需要可以只留 `window.UnitWidgets = {};`
4. 到 `assets/catalog.js` 把該單元的 `status` 改成 `'ready'`，並填上 `sections`

## 單元的獨立互動頁（例：自然五上 四季太陽3D）

- 內容較多、需要整頁操作的互動（例如 3D 模型），可以在單元資料夾中另建一個 `.html`，例如 `自然五上/單元1_太陽的祕密/四季太陽3D.html`。
- 樣式沿用 `../../assets/hub.css`（專用樣式以 `.s3d-` 開頭寫在 hub.css），並在該單元 `data.js` 的相關區塊放一個按鈕連過去。
- 3D 畫面用 Canvas 自行繪製，不依賴外部函式庫，離線也能使用。

## 新增一個科目（例：社會五上）

1. 建立 `社會五上/` 資料夾，複製 `自然五上/index.html` 進去，把 `data-subject="sci5a"` 改成 `soc5a`
2. 在 `assets/catalog.js` 對應的科目設定 `status: 'ready'`，並在 `units` 中登記單元
3. 依上面步驟新增單元

## data.js 題型速查

| type | 用途 | 主要欄位 |
|---|---|---|
| `single` | 單選 | `opts`、`ans: 索引` |
| `multi` | 複選（習作的「打✓」） | `opts`、`ans: [索引...]` |
| `classify` | 分類（例：✓ 與 ○） | `cats`、`items: [{t, a}]` |
| `fill` | 下拉選單填空，可放在表格中 | `text` 內寫 `{{答案\|選項1,選項2}}`；或共用 `options` 時只寫 `{{答案}}` |
| `open` | 開放題（不計分） | `ref` 參考答案 |

共同欄位：`explain`（作答後顯示的說明）、`src`（出處標籤）。區塊加上 `exam: true` 即為交卷模式。

單元設定 `shuffleOptions: true` 時，單選題選項會依題目 id 固定打散（每次開啟順序相同）；個別題目加 `keepOrder: true` 可保留原順序。

## 備註

- 學習進度存在各自瀏覽器的 localStorage，不會上傳，也不會在不同裝置間同步。
- 字型使用 Google Fonts（M PLUS Rounded 1c），離線時會自動改用系統字型。
