AND 閘：兩個都要成立 🔐

寶庫的門要兩把鑰匙同時打開才會開——這就是 AND（且）。紅石的 AND 要用 3 支火把，今天也要用 MakeCode 的「如果……而且……」做一次程式版的 AND，比比看哪個比較簡單。

🧱 拉桿、紅石火把、石頭、紅石粉、黏性活塞💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

📚 新元件小教室

🔐AND（且）輸入 A 而且 B 都有電，輸出才有電。
A=1 B=1 → 1，其他都是 0。
🕯️🕯️🕯️3 支火把的 ANDA、B 各接一支火把（反過來），兩支火把的線合在一起（OR），再接一支火把（再反過來）。
口訣：先反、再合、再反。

🔑 今天的重點

  • 為什麼這樣可以？只要 A 或 B 有一個「沒開」，它的火把就會亮，最後那支火把就會熄滅 → 燈不亮。
  • 只有 A、B 都開，前兩支火把都熄，最後那支才會亮。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：雙人寶庫門 🔐

🎒 準備物品：拉桿 ×2、石頭 ×3、紅石火把 ×3、紅石粉、黏性活塞（或鐵門）

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 寶庫門兩側各放一個拉桿（要兩個人分別扳）。
  2. 每個拉桿 → 紅石粉 → 石頭，石頭另一側插火把。
  3. 兩支火把的紅石粉合成一條，接到第三顆石頭，再插第三支火把。
  4. 第三支火把接到鐵門（或黏性活塞做的門）。兩人都扳開才會開門！
💡 蓋好後先測真值表 4 種組合；有一種不對，就從「第一支火把有沒有熄滅」開始檢查。
🐣 三、四年級：網頁補上最後一支火把，再照網頁的樣子在遊戲蓋。
🦊 五、六年級：網頁挑戰「從零開始做 AND」，不看提示自己蓋。

🎮 應用 2：程式版雙鑰匙 🗝️

🎒 準備物品：（MakeCode）黏性活塞門或鐵門

🧱 在遊戲裡做

  1. 用上一堂的反向燈技巧：門的電路旁留一格空位，程式會在那裡放紅石方塊。
  2. 照下面的 MakeCode 積木拼好。
  3. 一個人輸入 key1，另一個人輸入 key2，再輸入 open。
  4. 只輸入一把鑰匙就 open，看看會發生什麼事。
💡 程式的「而且」（and）就跟紅石的 AND 一樣，但不用蓋 3 支火把！
🐣 三、四年級：照積木拼，兩把鑰匙都有才開門。
🦊 五、六年級：加第三把鑰匙 key3，三把都有才開。

💻 MakeCode：程式版雙鑰匙寶庫

程式用「變數」記住鑰匙有沒有拿到，再用「如果 key1 而且 key2」判斷。和紅石的 AND 是同一個想法。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"key1"}
  vars: 設定 {key1} 為 {真}
  player: 說 {"拿到第 1 把鑰匙"}
player hat: 當聊天指令 {"key2"}
  vars: 設定 {key2} 為 {真}
  player: 說 {"拿到第 2 把鑰匙"}
player hat: 當聊天指令 {"open"}
  logic: 如果 {key1 而且 key2} 那麼
    blocks: 放置 [紅石方塊] 位於 {~0 ~0 ~2}
    player: 說 {"寶庫打開了！"}
  logic: 否則
    player: 說 {"還少一把鑰匙…"}
JavaScript
let key1 = false
let key2 = false
player.onChat("key1", function () {
    key1 = true
    player.say("拿到第 1 把鑰匙")
})
player.onChat("key2", function () {
    key2 = true
    player.say("拿到第 2 把鑰匙")
})
player.onChat("open", function () {
    if (key1 && key2) {
        blocks.place(REDSTONE_BLOCK, pos(0, 0, 2))
        player.say("寶庫打開了！")
    } else {
        player.say("還少一把鑰匙…")
    }
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 先建立兩個變數 key1、key2（變數分類 → 建立變數）。
  2. 「而且」在邏輯分類裡（and）。
  3. 站在固定位置輸入指令，紅石方塊會出現在面前 2 格，接到門的電路。
  4. 想重來：加一個 reset 指令，把兩個變數設回「假」並放置空氣。
📌 同一個世界裡只有一位玩家執行程式時最穩定；兩人合作時可以一人負責輸入指令、一人負責蓋門。

👩‍🏫 教師備註
  • 3 支火把的 AND 是本課最難的地方，三四年級可以只完成網頁「補最後一支火把」＋遊戲中照圖蓋。
  • 常見錯誤：合流的紅石粉碰到前面的火把或石頭，造成電流亂跑；請學生保持每條線之間空一格。
  • MakeCode 的變數建立後才會出現「設定」積木；可以先帶全班建立好兩個變數。
