📚 新元件小教室

⏩紅石中繼器把訊號補回 15；訊號只能往箭頭方向走；右鍵可以調延遲 1～4 格（每格 0.1 秒）。
📏訊號強度電源旁邊是 15，每走一格少 1。強度 1 也算有電，0 才是沒電。

🔑 今天的重點

  • 中繼器放的方向很重要：箭頭（三角形）要指向「電要去的地方」。
  • 中繼器像一個「單行道」，可以防止兩條線的電互相跑到對方那裡。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：30 格燈帶，修好它！ 📏

🎒 準備物品：（用 MakeCode 鋪好）拉桿、紅石中繼器

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 先用下面的 MakeCode 程式輸入 lamps 30，腳下會出現一排 30 盞燈，上面鋪滿紅石粉。
  2. 在第一格紅石粉旁邊放拉桿並打開。數一數：亮到第幾盞？
  3. 把第 15 格左右的紅石粉挖掉，換成中繼器（箭頭朝前進方向）。
  4. 後面的燈全部亮起來了！
💡 中繼器放反了，電就過不去。放之前先看看自己面向哪一邊：中繼器的箭頭會朝向你「面對的方向」。
🐣 三、四年級：在網頁和遊戲裡都修好燈帶。
🦊 五、六年級：挑戰 50 格燈帶，最少需要幾個中繼器？

🎮 應用 2：跑馬燈 🏃

🎒 準備物品：拉桿、紅石粉、紅石中繼器、紅石燈

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 拉桿 → 紅石粉 → 中繼器 → 紅石粉 → 中繼器……排成一排。
  2. 每段紅石粉旁邊（或下面）放一盞燈。
  3. 對中繼器按右鍵把延遲調到 4，打開拉桿看燈一顆一顆亮。
  4. 關掉拉桿，燈也會一顆一顆熄滅。
💡 延遲 1 格 = 0.1 秒。4 個延遲 4 的中繼器，最後一盞燈要等 1.6 秒才亮。
🐣 三、四年級：做出 5 盞燈的跑馬燈。
🦊 五、六年級：做成一個圈，讓跑馬燈繞著舞台。

💻 MakeCode：一秒鋪好 30 格燈帶

用程式「填充」可以瞬間鋪好很長的紅石線，方便測試訊號強度。聊天指令後面的數字可以決定要鋪幾格。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"lamps"} 參數 {num1}
  blocks: 填充 [紅石燈] 從 {~1 ~-1 ~0} 到 {~num1 ~-1 ~0} [取代]
  blocks: 填充 [紅石粉] 從 {~1 ~0 ~0} 到 {~num1 ~0 ~0} [取代]
JavaScript
player.onChat("lamps", function (num1) {
    blocks.fill(REDSTONE_LAMP, pos(1, -1, 0), pos(num1, -1, 0), FillOperation.Replace)
    blocks.fill(REDSTONE_WIRE, pos(1, 0, 0), pos(num1, 0, 0), FillOperation.Replace)
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 在平坦的地方，拼好積木後按 T 輸入 lamps 30。
  2. 腳下往東會出現 30 盞紅石燈（換掉地板），燈上面鋪滿紅石粉。
  3. 在自己腳下（燈帶起點）放拉桿並打開。
  4. 試試 lamps 15、lamps 16：哪一個全部都亮？
📌 紅石粉放在紅石燈「上面」，燈就一定會被點亮，這樣才能清楚看出訊號在哪裡用完。燈帶是往「東」（x 變大）鋪，請先按 F3 或開啟「顯示座標」確認方向。

👩‍🏫 教師備註
  • 燈帶程式會把地板換成燈，請在平坦世界操作，避免挖到洞。
  • 如果學生看不懂方向，可以在世界設定開啟「顯示座標」，讓學生觀察往東走時 X 變大。
  • 基岩版中繼器還有「鎖定」功能（從側面再接一個中繼器），🦊 學生可以自己探索。
