記憶電路：會記住的紅石 🧠

按一下開燈、再按一下關燈——家裡的電燈就是這樣。但按鈕只有一下下的電，紅石要怎麼「記住」現在是開還是關？今天認識銅燈（T 正反器）和火把記憶電路，也用 MakeCode 的「變數」來記住。

🧱 銅燈、按鈕、紅石比較器、紅石火把、鐵門💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 知道「記憶」＝電路能保持狀態，不會因為按鈕放開就消失。
  2. 做出一顆按鈕開關的燈和門（銅燈＋比較器）。
  3. 了解程式的變數也是一種記憶。

📚 新元件小教室

💡銅燈每收到一次新的訊號就切換一次：暗→亮→暗……會自己記住。它本身不會送電出去，要用比較器讀它（亮＝15）。
🧠T 正反器「按一下切換」的電路叫 T 正反器（Toggle）。銅燈就是現成的 T 正反器。
🔁火把記憶（鎖存器）兩支火把互相控制對方：一支亮，另一支就熄，會一直保持，直到按另一邊的按鈕。

🔑 今天的重點

  • 銅燈需要 Minecraft 1.21 以上的版本。遊戲裡找不到銅燈，就先在網頁做，遊戲裡改做火把記憶電路。
  • 記憶電路就是電腦「記憶體」的最小單位：記住一個 0 或 1。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：一顆按鈕開關燈 💡

🎒 準備物品：按鈕、紅石粉、銅燈、紅石比較器、鐵門

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 牆上放按鈕，鋪紅石粉接到銅燈。
  2. 按一下 → 銅燈亮；再按一下 → 熄。
  3. 🦊 在銅燈旁邊放比較器（背對銅燈），前面接紅石粉到鐵門。
  4. 按一下開門、再按一下關門，門會一直保持！
💡 銅燈放久了會氧化變綠，亮度會變暗，但開關功能一樣。
🐣 三、四年級：做出一顆按鈕開關燈。
🦊 五、六年級：加比較器，做出一顆按鈕開關門。

🎮 應用 2：會記住的警報 🚨

🎒 準備物品：按鈕 ×2、石頭 ×2、紅石火把 ×2、紅石粉、紅石燈

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 在網頁按「觸發 S」：警報燈亮起來，而且一直亮著。
  2. 按「重設 R」：警報燈熄滅。
  3. 打開「顯示訊號強度」，用「走一步」看兩支火把怎麼互相控制。
  4. 🦊 照網頁的樣子在遊戲蓋出來，把「觸發」換成壓力板：有人踩過就一直響，直到警衛按重設。
💡 這個電路一開始要「其中一支火把亮、另一支熄」；如果兩支一起亮，會互相打架閃個不停，按一下重設就好了。
🐣 三、四年級：在網頁玩懂觸發和重設。
🦊 五、六年級：在遊戲蓋出壓力板觸發的警報。

💻 MakeCode：程式版開關：變數就是記憶

程式用變數 light 記住燈現在是開還是關。每次輸入指令就把它「反過來」——跟銅燈一模一樣。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"light"}
  vars: 設定 {light} 為 {不是 light}
  logic: 如果 {light} 那麼
    blocks: 放置 [紅石方塊] 位於 {~0 ~0 ~2}
    player: 說 {"開燈"}
  logic: 否則
    blocks: 放置 [空氣] 位於 {~0 ~0 ~2}
    player: 說 {"關燈"}
JavaScript
let light = false
player.onChat("light", function () {
    light = !(light)
    if (light) {
        blocks.place(REDSTONE_BLOCK, pos(0, 0, 2))
        player.say("開燈")
    } else {
        blocks.place(AIR, pos(0, 0, 2))
        player.say("關燈")
    }
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 建立變數 light。
  2. 「不是」在邏輯分類（not）：把「真」變「假」、「假」變「真」。
  3. 面前 2 格旁邊放燈，輸入 light 好幾次，燈會一開一關。
  4. 想一想：變數 light 記住的是什麼？
📌 「設定 light 為 不是 light」就是程式版的 T 正反器。
