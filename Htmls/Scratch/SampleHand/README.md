# 手勢模組教室（Handpose2Scratch × 自訂積木）

> 建立日期：2026-09-25　·　參考專案：`20260924_手勢辨識_數字與猜拳_Web`
> 產生工具：`20260923_Scratch專案產生器`（sb3lib／svgkit）、`20260924_SB3轉網頁工具`

把「手勢辨識大挑戰」的偵測程式拆成 **10 個自訂積木（函式）**，每個都有明確的**輸入與輸出**，
讓學生一個模組一個模組學，最後用「工具箱」做自己的作品。

## 零、需求與決策紀錄（新對話接手請先看這裡）

**使用者的原始需求（2026-09-25）**
> 參考 `20260924_手勢辨識_數字與猜拳_Web`，把功能**模組化**，做成一個一個**函式**，
> 讓學生能一個一個模組結構學習，例如判斷手勢（比出 1、2、3、4、5、0）、剪刀石頭布，
> 或其他可以讓學生使用的模組；製作 Scratch .sb3 檔案，並製作學習互動網頁。

**使用者確認過的選擇**
| 問題 | 使用者的決定 |
|---|---|
| sb3 怎麼切 | **每個模組一個 .sb3 ＋ 一個「完整工具箱」.sb3** |
| 模組範圍 | **10 個全做**（1～7 來自參考專案，8～10 是延伸） |

**我（Claude）替使用者做的設計決定與理由**（使用者沒有反對，之後要改可以直接改）
- 所有自訂積木集中在「手勢模組」角色（大腦）：Scratch 的自訂積木只能在同一個角色裡呼叫。
- Scratch 自訂積木不能回傳值 → 約定「輸出寫進全域變數」，其他角色只讀變數。
- 模組 3 做成三個參數 `判斷手指 (指尖)(關節)(目前)`，讓同一塊積木用四次，這是教「參數」的核心。
  （已查證 Handpose2Scratch 官方原始碼的點位選單可以放參數：`acceptReporters: true`。）
- 模組 8 的手勢密碼用 `?` 當萬用字元，手勢清單放在兩個清單裡，加新手勢不用改程式。
- 模組 10 捏合用「橫＋直距離」（不用平方根）與兩個門檻（遲滯），捏下去那一瞬間廣播「捏一下」。
- 模組 6 以後有鍵盤模式（K），0～9 對應手勢；模組 10 用滑鼠代替，沒有攝影機也能上課。
- 網頁上的積木圖由 .sb3 **自動轉出**（`export_blocks.py`），不手寫，避免兩邊不一致。
- 每個 .sb3 都轉成可離線、可用攝影機的網頁版（`play/`），11 個共用一份引擎與手部模型（約 26 MB）。
- 參考專案的產生器原始碼沒有留下來，判斷邏輯是用 `tools/decompile_sb3.py` 從參考 .sb3 拆出來的，數值完全沿用（第五版）。

**還沒做／可以延伸的方向**
- 真人在攝影機前逐一試玩 10 個模組（目前只用假座標與 Chromium 假攝影機測過）。
- 可能的新模組：左右手判斷、揮手方向（手腕 x 的變化速度）、手在畫面的九宮格位置、雙手手勢。
- 教學網頁目前沒有「教師版說明」（上課時數、分組建議），需要時可以加一頁。

**設計約定**（教材第 0 章有說明）
1. 所有自訂積木放在「手勢模組」角色（大腦）—— Scratch 的自訂積木只能在同一個角色裡呼叫。
2. Scratch 自訂積木不能回傳值 → 函式把結果寫進「輸出變數」，全部設為「所有角色適用」。
3. 其他角色（手指燈、數字卡、猜拳手、氣球…）只讀變數，不自己偵測。
4. 每塊自訂積木都勾「執行時不重新整理畫面」。
5. 模組 6 以後有鍵盤模式（K）：0～5 ＝ 數字、6 我愛你、7 搖滾、8 打電話、9 手槍；模組 10 用滑鼠代替。D 開關骨架點。

判斷規則與參考專案第五版完全相同（手腕守門、手長／手寬兩把尺、四指比 y、拇指量到小指掌根 ×1.35、
餘裕 0.08、穩定 0.15 秒、掉格容忍 0.4 秒）。新增的是模組 8（萬用比對＋`?`）與模組 10（捏合，遲滯 0.25／0.4 手長）。

## 三、怎麼用

- 學生：打開 `index.html` → 模組教學。每章有「⬇ .sb3」與「🎥 用攝影機試玩」。
- .sb3 請用 **stretch3.github.io** 開啟（已內含 Handpose2Scratch）。
- 網頁版 `student/play/*/index.html` 直接雙擊就能用攝影機；`play/engine/` 必須跟著一起複製。

### 修改流程（改了任何模組都要跑完這四步）

```bash
cd tools
python build_modules.py        # 1. 產生 .sb3（可加編號只產生一個：python build_modules.py 6）
python export_blocks.py        # 2. 更新網頁上的積木圖
python make_play.py            # 3. 更新網頁版
npm install && node test_modules.js   # 4. 測試（或 node test_modules.js 6）
python ../../20260923_Scratch專案產生器/lint.py ../student/sb3/模組06_穩定判斷.sb3
cd ..
python tools/test_web.py              # 5. 改了網頁（student/index.html、assets/）時
python tools/test_play_pages.py       # 6. 看網頁版畫面
```

**改哪裡**：模組的積木 → `tools/build_modules.py` 的 `mod1()`～`mod10()`；示範角色 → 同檔的 `sp_*()`；
教學文字 → `student/index.html`；互動實驗 → `student/assets/lessons.js`；網頁樣式 → `student/assets/mod.css`。

## 四、踩過的坑（本專案新發現）

1. **`sb3lib` 的 `hx()`／`hy()` 不能收積木**：它們會 `str(n)`，積木 id 會被當成字面文字。
   要把自訂積木的參數放進點號選單，要自己用 `menu(..., B, '1')`（見 `build_modules.py` 的 `HX()`）。
   Handpose2Scratch 官方原始碼的 landmark 選單是 `acceptReporters: true`，所以參數放進去在真的 stretch3 也能用（已實際開啟確認）。
2. **Scratch 的「＝」會把長得像數字的字串當數字比**：`01100 = 1100`、`0000 = 00000` 都**成立**。
   指型的比較要一個字一個字比（模組 8），或確保兩邊位數相同。
3. **空白和數字比大小是「不成立」**（Scratch 的 `Cast.compare` 遇到空白會改用字串比較），
   所以「手腕 x > −250」擋得住偵測不到的情況；但空白拿去**定位**會變成 0。
   （產生器 README 坑 3 寫「比大小會當成 0」並不精確，行為上的結論一樣：要先守門。）
4. **還沒按綠旗時，所有角色都在 (0,0)**：`build_modules.py` 的 `initial_props()` 會照綠旗程式開頭的
   定位／尺寸／顯示・隱藏設定角色初始狀態，打開檔案時畫面就和執行時一樣。
5. **stretch3 的擴充積木是英文點位名稱，積木很寬**，註解要放在 x = 1080 以後才不會蓋到積木。
6. **鍵盤模式要連「每一格」的變數一起設定**：只設「確定」變數時，手指燈（讀拇指～小指）不會亮 —— 畫面截圖才抓到。

## 六、為什麼沒有 GUI／CLI 版本
