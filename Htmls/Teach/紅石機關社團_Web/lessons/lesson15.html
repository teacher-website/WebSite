2×2 活塞門：第一個大型機關 🏰

前 14 堂學到的元件，要開始組合成大型機關了！2×2 活塞門是最經典的紅石作品：4 個方塊同時收進牆裡，門口就打開。先用 MakeCode 一秒蓋好門框，再專心接線。

🧱 黏性活塞 ×4、石頭、拉桿／壓力板、紅石粉、紅石火把、中繼器💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 會畫設計圖，把大機關拆成「門框、活塞、線路」三部分。
  2. 做出拉桿控制的 2×2 活塞門。
  3. 🦊 用火把做出「平常關著、踩壓力板才開」的門。

📚 新元件小教室

🗺️設計圖大機關先畫在格子紙上：哪裡是活塞、哪裡是線，再動手蓋。
🏰2×2 門的原理門口左右兩邊各有上下 2 支黏性活塞，每支黏著 1 塊門板。通電 → 4 塊門板推出來 → 關門。
🔄加火把反過來在線路上加一支火把：平常有電（門關），按開關後沒電（門開）。

🔑 今天的重點

  • 網頁是「從上往下看」的俯視圖，只看得到下排的活塞；遊戲裡上排也要放一樣的，再用紅石把上下都接到。
  • 活塞的電要同時送到 4 支，線路要接到每一支的「後面或側面」。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：拉桿控制的 2×2 門 🏰

🎒 準備物品：（MakeCode 蓋門框）黏性活塞 ×4、石頭 ×4、紅石粉、紅石火把、拉桿

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 用 MakeCode 輸入 frame，面前出現有 2×2 門口的牆。
  2. 門口左邊牆裡上下各放一支黏性活塞（朝右），右邊上下各放一支（朝左），每支前面黏一塊石頭。
  3. 在牆後面鋪紅石粉接到 4 支活塞（上排可以用石頭＋紅石火把把電往上送）。
  4. 拉桿打開 → 4 塊石頭推出來關門；關掉 → 門打開。
💡 上排活塞最難接：在上排活塞的後面放一顆石頭，石頭下面放一支紅石火把頂著——火把會讓上面的石頭帶電，石頭再讓旁邊的活塞動。先在網頁把下排想清楚，再到遊戲處理上排。
🐣 三、四年級：做出 1×2（只有下排）的門，再挑戰上排。
🦊 五、六年級：做出完整的 2×2 門。

🎮 應用 2：平常關著、踩了才開 🚶

🎒 準備物品：壓力板 ×2、紅石火把、石頭

🧱 在遊戲裡做

  1. 在網頁完成 🦊 挑戰：把線路上的一格換成火把。
  2. 在遊戲裡門前後各放一個壓力板。
  3. 壓力板 → 石頭 → 紅石火把 → 原本的活塞線路。
  4. 平常火把亮 → 門關著；踩上壓力板 → 火把熄 → 門打開，走過去門又關上！
💡 這就是第 2 堂的 NOT！大型機關都是用小元件組合起來的。
🐣 三、四年級：在門兩側各加一個按鈕。
🦊 五、六年級：做出壓力板自動門。

💻 MakeCode：一秒蓋好門框

大型機關最花時間的是蓋牆。用「填充」先蓋好整面牆，再用一次填充把門口挖空，就能專心在紅石線路上。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"frame"}
  blocks: 填充 [石磚] 從 {~-3 ~0 ~3} 到 {~3 ~4 ~3} [取代]
  blocks: 填充 [空氣] 從 {~-1 ~0 ~3} 到 {~0 ~1 ~3} [取代]
JavaScript
player.onChat("frame", function () {
    blocks.fill(STONE_BRICKS, pos(-3, 0, 3), pos(3, 4, 3), FillOperation.Replace)
    blocks.fill(AIR, pos(-1, 0, 3), pos(0, 1, 3), FillOperation.Replace)
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 找一塊空地，面向南方（Z 變大的方向）輸入 frame。
  2. 面前 3 格會出現 7 格寬、5 格高的石磚牆，中間有 2×2 的門口。
  3. 想把門做大一點？改數字：牆寬、門口位置都可以調整。
  4. 牆後面挖空間放活塞和線路。
📌 座標 ~-3 ~0 ~3：x 往左 3、y 不變、z 往前 3。這裡的「前」是世界的南方，不是你面向的方向。
