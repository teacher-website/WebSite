Scratch 作品的「門面」：片頭 · 故事 · 選單

貓咪甜點店

一份作品給人的第一印象，就是片頭、故事簡介和主選單。
這份教材把它做成一間甜點店：招牌落下、店名放大、貓店長滑進來打招呼， 看完故事就進到選單，三個甜點分別是遊戲一、二、三——之後把你自己的遊戲接上去就好。

這份教材的重點　不是甜點店，而是三件每個作品都用得到的功夫： ① 用一個變數管理所有畫面、② 每個段落都能跳過、③ 讓動畫看起來「有彈性」。 每個效果都會給入門與進階兩種做法，先做得完，再做得好看。

第 2 章

畫面切換：一個變數就夠了

想法：不要用「一堆訊息」，用「一個變數」

很多人做選單會做成：按這個按鈕廣播 A、按那個廣播 B，角色各自隱藏顯示…… 畫面一多就會亂掉，常常出現「上一個畫面的東西忘了隱藏」。

改成這樣就清楚了　 用一個變數 畫面 記住現在在哪一頁，再用一個訊息 切換畫面 通知大家。
每個角色收到訊息時只問自己一句：「現在是我的畫面嗎？是就顯示，不是就隱藏。」

舞台：切到某個畫面

每個角色：我該不該出現

好處　以後要加第六個畫面（例如「排行榜」），不用改任何舊角色的程式， 只要新角色自己判斷 畫面 ＝ 排行榜就好。

主程式：一個重複無限次，就是整個作品的流程

為什麼播完還要「再確認一次」　因為播片頭的時候，玩家可能按了選單的按鈕把 畫面 改掉了。如果不確認就硬把畫面設成下一頁，玩家的操作就被蓋掉了。
「回到哪」在做什麼　第一次玩：片頭 → 故事 → 說明 → 選單。 但如果是從選單按看故事進來的，看完應該回選單才對。 所以按鈕會先把 回到哪 設成「選單」，播完再看這個變數決定去哪裡。
第 3 章

Skip：讓每個段落都能跳過

關鍵：不要用內建的「等待 n 秒」

內建的「等待 2 秒」一旦開始，就一定要等滿 2 秒，按什麼都沒用。 所以我們自己做一塊「等 n 秒（可跳過）」，整份作品的等待都用它。

跳過鈕只做一件事——把 跳過 設成 1：

為什麼這樣就會「整段」跳掉　因為片頭、故事、說明裡面所有的等待都用同一塊積木， 所以 跳過 一變成 1，它們會同時結束，畫面就一路衝到最後。
兩個容易忘記的地方　 ① 換畫面時要把「跳過」設回 0，不然下一段會被上一次的跳過一起跳掉。
② 自訂積木只屬於自己的角色。貓店長要在自己的角色裡再做一塊一樣的「等 n 秒（可跳過）」。
第 4 章

片頭動畫：先做完，再做好看

✨ 入門 vs 進階

按播放看差別

同樣是「招牌從上面掉下來」，兩種做法的感覺差很多。按下面的按鈕比較看看。

入門：直接滑到定位

招牌

滑行 0.6 秒到 y ＝ 76。穩、快、不會錯。

進階：衝過頭再彈回來

招牌

先滑到比目標低一點 → 往上彈過頭 → 回到定位，同時淡入放大。

「彈性」的秘密就是衝過頭　真實世界的東西掉下來會反彈。 程式只要多兩句「滑行到超過目標的位置」再「滑回來」，看起來就會有重量感。

積木：招牌落下

入門版

進階版

動畫一定要補最後一句「定位」　玩家可能在動畫播到一半按跳過。 如果沒有最後那句「定位到 x:0 y:76」，招牌就會停在半空中。
口訣：動畫可以被跳過，但結果一定要正確。

積木：店名一邊放大一邊淡入

兩個效果一起做　只有放大會有點生硬，只有淡入會有點無聊， 同時做就會有「登場」的感覺。重複 12 次、每次尺寸 +5、幽靈 −9，剛好從 40 變 100、從透明變清楚。
出場要有先後順序　招牌 → 店名 → 副標 → 貓店長，中間各等一下下。 全部同時出現，觀眾會不知道要看哪裡。
第 5 章

故事簡介：打字機效果

⌨️ 打字機實驗室

改速度、按跳過

改改看句子和速度，再按「跳過」試試看。

這句話有 0 個字 → 迴圈就要重複幾次。

積木：打字 ◯

原理只有一句話　 把「第 n 個字元」一個一個用「字串組合」接到後面，每接一個就「說出」一次。
顯示文字 ＝ 字串組合（顯示文字，第 第幾個字 個字元）
中文要注意　「字串的長度」算的是字元，中文一個字就是一個字元，所以中文可以正常使用。 標點符號也算一個字。

整段故事

說出空白就會把對話框收起來——很多人會忘記這一句，結果對話框跟著角色跑到下一個畫面。

第 6 章

遊戲說明：三頁輪播

舞台：一頁一頁換

說明卡：淡入＋放大

為什麼用「廣播並等待」　舞台負責時間（每頁停 2.4 秒）， 說明卡負責長相（換造型、淡入）。分工清楚，以後要加第四頁只要多一個造型。
第 7 章

主選單與按鈕

滑鼠滑過去會變大

為什麼不要一次變大到底　「尺寸設為 112」是瞬間變大，很生硬。 改成「每次 +4、直到 112」，眼睛看到的就是慢慢脹大，離開時再慢慢縮回去。 這是所有按鈕都適用的小技巧。

點下去 → 進遊戲畫面

一定要先確認「畫面 ＝ 選單」　不然在片頭播到一半時， 玩家亂點到甜點原本的位置也會直接跳進遊戲。按鈕要知道自己現在有沒有上班。

回片頭／看故事／看說明

三顆按鈕只用一個角色　做 3 個分身，用 編號 決定自己是哪一顆、 位置用 x ＝ 編號 × 160 − 320 算出來（−160、0、160）。 要改成四顆時，只要把 3 改成 4、公式稍微調一下就好。
第 8 章

遊戲畫面與小裝飾

三個遊戲共用一個角色

👉 這裡就是接自己遊戲的位置　目前遊戲畫面只有標題和「回選單」。 等你把遊戲做好，就在這裡加上「如果 目前遊戲 ＝ 1 → 廣播 開始遊戲一」， 再讓你的遊戲角色收到訊息後開始跑。整個選單系統完全不用改。

小裝飾：讓畫面活起來

分身一定要刪掉　沒有「刪除這個分身」的話， 分身會一直累積，玩不到一分鐘畫面就會開始卡。
另外分身太多也會拖慢速度，本體做分身的間隔不要小於 0.3 秒。
第 9 章

測試、挑戰與檢核

建議的測試順序

  1. 一路按跳過：片頭、故事、說明各按一次跳過，要能順順地到選單，而且每個角色都停在正確的位置。
  2. 完全不按：讓它自己播完，一樣要到選單。
  3. 三個甜點各點一次：標題要對（遊戲一／二／三），按回選單要回得來。
  4. 從選單看故事：看完要回選單，不可以繼續跑到說明。
  5. 亂點測試：在片頭時亂點畫面各處，不應該跳進遊戲。
  6. 放著不動一分鐘：看看小裝飾有沒有越來越多、畫面有沒有變慢。

可以調整的數字

數字預設調整後
片頭總長度6 秒調長可以放更多動畫，但別超過 10 秒，觀眾會不耐煩
打字速度0.045 秒／字調小會變快；中文建議 0.04～0.08
說明每頁停留2.4 秒字多就調長一點
按鈕放大上限112%太大會蓋到旁邊的按鈕
小裝飾間隔0.3～0.9 秒調太小畫面會卡

🔧 遇到問題先看這裡

症狀常見原因
按跳過沒反應某個地方還在用內建的「等待 n 秒」
跳過之後角色停在奇怪的位置動畫最後忘了補「定位到 ◯ ◯」
下一段自己被跳掉了換畫面時忘了把 跳過 設回 0
上一個畫面的東西還留著那個角色沒有寫「否則 → 隱藏」
從選單看完故事卻跑到說明回到哪 忘了設，或播完忘了判斷
對話框跟著跑到下一頁故事結束時忘了「說出（空白）」
越玩越卡分身沒有刪除

挑戰任務

⭐ 換成自己的店把甜點換成自己的主題，店名和三個遊戲名稱一起改
⭐ 加背景音樂在舞台加「重複播放音樂」，進遊戲畫面時換一首
⭐⭐ 加「設定」畫面多一個畫面放音量開關，試試看新增畫面有多簡單
⭐⭐ 選單加說明泡泡滑鼠滑到甜點上時，貓店長說出那個遊戲的玩法
⭐⭐⭐ 接上真的遊戲在遊戲標題畫面廣播「開始遊戲一」，把你做好的遊戲接上去
