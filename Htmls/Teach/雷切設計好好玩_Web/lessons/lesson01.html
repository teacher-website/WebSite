📚 魔法小教室

🔦雷射把光集中成很細、很強的一束，打在木板上，木頭會瞬間燒掉變成煙。
✂️切割雷射力量大、走得慢 → 把板子切斷。
✏️雕刻雷射力量小、走得快 → 只燒掉表面，留下咖啡色的圖案。
🪵密集板（MDF）木屑壓成的板子，表面平、好切、便宜。本社團用 3 mm 厚。
🖥️Inkscape免費的向量繪圖軟體，用來畫要切的圖案。
📡Beam StudioFlux 的雷射軟體，把圖案送到 Beambox 雷射切割機。

🔑 今天的重點

  • 雷射切割時一定要有人看著，蓋子一定要關、排風一定要開。
  • 只切老師準備的材料（PVC、人造皮革等會產生有毒氣體）。
  • 看到持續的火焰：按暫停 → 叫老師 → 不要打開蓋子。

🛠️ 動手做

🛠️ 任務 1：我的第一張 Inkscape 圖

🎒 準備：電腦、Inkscape 1.3 以上
  1. 打開 Inkscape，選「新文件」。
  2. 按 R，在畫布上拖出一個方形。
  3. 按 E 拖出圓形；按住 Ctrl 拖曳可以畫正圓。
  4. 按 S 選取，拖拉可以移動；拉四個角的箭頭可以改大小，再點一次會變成旋轉箭頭。
  5. 點畫面下方的調色盤換顏色。
  6. 按 Ctrl＋S 存到「雷射社團／座號_姓名／第01堂.svg」。
🐣 三、四年級：畫出 3 個不同顏色的形狀。
🦊 五、六年級：只用方形和圓形，拼出一個機器人或房子。
