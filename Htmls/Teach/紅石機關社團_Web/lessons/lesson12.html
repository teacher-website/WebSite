日光感測器與標靶方塊 🌙

日光感測器能感覺天有多亮：白天亮度越高訊號越強；切換成「夜晚模式」就變成天越黑越強——自動路燈就靠它！標靶方塊被箭射中會發電，越接近中心越強，可以做射箭計分板。

🧱 日光感測器、標靶方塊、弓與箭、紅石粉、紅石燈💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

📚 新元件小教室

🌞日光感測器白天越亮訊號越強（中午最強 15）。右鍵點一下變成夜晚模式（藍色）：天越黑訊號越強。
🎯標靶方塊被箭（或雪球）打中會發出訊號：正中央 15，越外圈越弱。
🏹射箭小技巧拉弓越久箭飛越遠；創造模式的箭用不完。

🔑 今天的重點

  • 日光感測器要放在看得到天空的地方，上面不能有屋頂。
  • 標靶的訊號只有一下下（約 1 秒）。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：天黑自動亮的路燈 🌙

🎒 準備物品：日光感測器、紅石粉、紅石燈、柵欄（燈柱）

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 用柵欄疊 3 格當燈柱，最上面放紅石燈。
  2. 在燈柱旁的地上放日光感測器，右鍵切換成夜晚模式（變藍色）。
  3. 紅石粉從感測器接到紅石燈。（先把燈放在地上做成「地燈」最簡單；🦊 再想辦法把電送上燈柱。）
  4. 用 MakeCode 的 night 指令讓天變黑，路燈自動亮起來！
💡 天剛變黑時訊號還很弱；感測器離燈太遠，弱訊號可能傳不到。
🐣 三、四年級：做出 1 盞自動路燈。
🦊 五、六年級：用一個感測器控制整條街 5 盞路燈（記得補中繼器）。

🎮 應用 2：射箭計分板 🎯

🎒 準備物品：標靶方塊、紅石粉、紅石燈 ×15、弓與箭

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 放一個標靶方塊當靶子。
  2. 從標靶後面鋪 15 格紅石粉，每格下面放一盞燈當分數條。
  3. 退後 10 格射箭：射越準，亮越多盞燈！
  4. 和同學比賽，看誰能亮最多。
💡 在網頁裡用 🖐️ 點標靶的中心和邊緣，看看數字差多少。
🐣 三、四年級：做出計分板。
🦊 五、六年級：加上鐵門：射中 12 分以上門才開（燈放在第 12 格後面接門）。

💻 MakeCode：一秒切換白天和晚上

等遊戲真的天黑要好幾分鐘。用程式直接改時間，馬上就能測試路燈。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"day"}
  gameplay: 時間設為 [白天]
player hat: 當聊天指令 {"night"}
  gameplay: 時間設為 [夜晚]
JavaScript
player.onChat("day", function () {
    gameplay.timeSet(gameplay.time(DAY))
})
player.onChat("night", function () {
    gameplay.timeSet(gameplay.time(NIGHT))
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 拼好兩個積木。
  2. 輸入 night：天馬上變黑，路燈亮了嗎？
  3. 輸入 day：天亮了，路燈熄了嗎？
  4. 🦊 加一個 dusk（黃昏）指令，看看黃昏時路燈亮不亮。
📌 若世界設定開啟了「日夜循環」，時間之後還是會繼續走。

👩‍🏫 教師備註
  • Minecraft Education 可在世界設定關閉「日夜循環」，配合 MakeCode 切換時間更好控制。
  • 射箭請規劃射擊區，避免射到別人的作品；或改用雪球（發射器也可以丟雪球）。
  • 網頁的日光數值是簡化的曲線（6 點、18 點為 0，中午 15），遊戲實際數值會受天氣、高度影響。
