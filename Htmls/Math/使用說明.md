# 數學出題小幫手（Web 版）

線上編輯數學考卷、學習單、口算練習與格線簿，匯出 A4 PDF。

## 開啟方式
直接用 Chrome / Edge 開啟 `index.html` 即可（不需安裝）。
`lib/` 資料夾內是 PDF 匯出與 LaTeX 公式元件，請與 index.html 放在一起；若缺少會自動改由網路載入。

## 主要功能
- **範本庫**：推薦／試卷／計算練習／數學素材／格線簿／表格／我的範本，共 28 種範本。
- **版面**：複習卷、小考卷、學習單、緞帶標題表頭；幾欄幾列；點選格子後左右／上下切割、合併、刪除；拖曳格子邊界調整比例；框線、內距、垂直對齊；A4 直式／橫式、邊界、頁碼。
- **題型**：大題標題、自動題號、選擇題、是非題、填充題、比大小、橫式題組、應用題、連連看、答案括號、作答線、空白間距、文字方塊、表格、分隔線（含剪下線）、⚡快速出題。
- **數學工具**：分數／帶分數、次方、根號、循環小數、LaTeX 公式、直式加減乘、直式除法、短除法、數線、時鐘、定位板、數的分與合、圖像數量、骰子、錢幣、格線（方格／點格／橫線／田字格／米字格）。
- **圖形圖表**：19 種平面與立體圖形、長條圖、橫條圖、折線圖、圓形圖。
- **符號**：運算、比較、單位、圈圈數字、分數字元、上下標、幾何、代數希臘、箭頭、中文數字、括號、圖案。
- **解答**：每個空格都能設定答案，「解答模式」以紅字預覽；可匯出題目卷、解答卷或合併檔。

## 快速語法（題目輸入框）
| 輸入 | 效果 |
|---|---|
| `{3/4}` | 分數 |
| `{2 1/3}` | 帶分數 |
| `[答案]` | 空格（解答卷顯示紅字） |
| `[]` | 空白方框 |
| `x^2` | 次方 |

## 儲存與分享
- 自動暫存在瀏覽器中。
- **儲存專案**（Ctrl+S）：下載 `.mathpaper.json`，可在別台電腦「開啟專案」。
- **匯出／匯入版型**：只包含紙張、表頭、欄列切割設定，套用時保留目前題目。
- **存成我的範本**：保存在本機瀏覽器的「我的範本」分類。

## 輸出
- **匯出 PDF**：直接下載 A4 PDF（可選解析度）。
- **列印**：在列印視窗選「另存為 PDF」可得到向量文字的 PDF。

## 快速鍵
Ctrl+Z 復原、Ctrl+Y 重做、Ctrl+S 儲存專案、Ctrl+P 列印、Delete 刪除選取元件、Enter 編輯選取元件、Esc 關閉視窗。
