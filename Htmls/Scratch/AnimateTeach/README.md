# Scratch 動畫製作・互動教學

> 建立日期：2026-09-21　·　對象：國小高年級　·　狀態：**學生互動教學＋教師手冊，已完成**
> 原作：**60319 李昀宸**「動畫教學」（Scratch 專案：18 頁投影片＋程式內 9 則註解）

## 一、這個專案是什麼

把李昀宸同學用 Scratch 做的「動畫教學」投影片，改編成一份**可以動手操作的互動教學文件**。
原作的每一頁重點都保留並標示出處（「昀宸說」＋原頁碼），再補上「為什麼要這樣做」的說明與互動示範。
另外把他藏在 .sb3 程式裡的註解逐則整理成第 5 章。

## 四、積木文字的依據

- 原作投影片截圖中出現的積木，照截圖。
- 其餘積木（播放音效、圖層、建立分身、碰到鼠標、滑鼠鍵被按下、等待直到、不成立、面朝、sin 數值、乘號等）
  已對照 **Scratch 官方繁體中文翻譯檔**（scratch-l10n `editor/blocks/zh-tw.json`）逐一確認。
- 注意：Scratch 的四則運算積木顯示為 `+` `-` `*` `/`（半形），**乘號是 `*` 不是 `×`**。

## 五、儲存

## 六、署名與公開

頁面保留原作者學號與姓名（投影片第 2 頁本身也有）。
若要放到**校外公開網站**，建議先取得原作者本人與家長同意；如需匿名化，替換 `student/assets/slides/s02.jpg`
並修改 `student/index.html`、`teacher/index.html`、根目錄 `index.html` 中的署名即可。

## 七、原作程式的觀察（教師手冊第五節）

1. 第 1 頁按「上一頁」會繞到最後一頁（造型編號 0 → Scratch 繞回最後一個）。
2. 「上一頁」箭頭分身有兩層「重複無限次」，外層多餘但不影響功能。
3. 造型名稱順序為 costume1–14、17、16、18、15；播放依清單順序，功能正常。
4. 舞台與幻燈片角色上各留一塊未連接的積木、一個未使用的變數，皆附註解，屬刻意示範。
5. 淡入迴圈沒有等待，約 0.33 秒完成。
6. 「換頁（造型）」需造型與音效同名，不一致時無聲且不報錯。
