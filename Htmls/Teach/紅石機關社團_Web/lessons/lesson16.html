📚 新元件小教室

🔢密碼鎖的想法每根拉桿都檢查一次：拉錯就送出「錯誤訊號」。只要有任何一個錯誤訊號（OR），門就不開（NOT）。
🕯️要「開」的拉桿拉桿 → 石頭 → 火把：拉桿沒開時火把亮＝錯誤訊號。
🔴要「關」的拉桿拉桿 → 直接紅石粉：拉桿被打開＝錯誤訊號。

🔑 今天的重點

  • 所有錯誤訊號接到同一條線（OR），最後再接一支火把（NOT）到門：沒有任何錯誤 → 火把亮 → 開門。
  • 改密碼＝把某一欄的「火把」和「紅石粉」交換。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：4 位數拉桿密碼鎖 🔢

🎒 準備物品：拉桿 ×4、石頭、紅石火把、紅石粉、鐵門

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 牆上排 4 根拉桿，每根之間空一格。
  2. 照網頁：要「開」的拉桿下面接 石頭＋火把；要「關」的直接接紅石粉。
  3. 4 欄在下面合成一條線 → 石頭 → 火把 → 鐵門。
  4. 測試：只有密碼正確門才開；把密碼寫在紙上交給隊友試。
💡 每一欄之間要空一格，不然火把的電會跑到隔壁欄。
🐣 三、四年級：網頁完成密碼 1010，在遊戲照圖蓋。
🦊 五、六年級：網頁挑戰改成 0110，並在遊戲改成自己的密碼。

🎮 應用 2：聊天密碼門 💬

🎒 準備物品：（MakeCode）鐵門或活塞門

🧱 在遊戲裡做

  1. 照下面的積木拼好，密碼先設 1234。
  2. 門的電路旁留一個空位，程式會在那裡放紅石方塊 3 秒。
  3. 輸入 pw 1111：門不開，聊天室說密碼錯誤。
  4. 輸入 pw 1234：門打開 3 秒後自動關上！
💡 拉桿密碼只有 0 和 1，4 位數只有 16 種可能；數字密碼 0000～9999 有 10000 種，哪個比較難破解？
🐣 三、四年級：照積木做出密碼門。
🦊 五、六年級：加一個變數記錄「猜錯幾次」，錯 3 次就說「鎖住了！」。

💻 MakeCode：聊天密碼門

程式可以比對任何數字，密碼的組合比拉桿多很多；還能限制猜錯次數。這就是電腦密碼的基本概念。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"pw"} 參數 {num1}
  logic: 如果 {num1 = 1234} 那麼
    player: 說 {"密碼正確，門打開了！"}
    blocks: 放置 [紅石方塊] 位於 {~0 ~0 ~2}
    loops: 暫停 {3000} 毫秒
    blocks: 放置 [空氣] 位於 {~0 ~0 ~2}
  logic: 否則
    player: 說 {"密碼錯誤！"}
JavaScript
player.onChat("pw", function (num1) {
    if (num1 == 1234) {
        player.say("密碼正確，門打開了！")
        blocks.place(REDSTONE_BLOCK, pos(0, 0, 2))
        loops.pause(3000)
        blocks.place(AIR, pos(0, 0, 2))
    } else {
        player.say("密碼錯誤！")
    }
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 「=」比較積木在邏輯分類。
  2. 輸入指令時，指令和數字中間要空一格：pw 1234。
  3. 門打開 3 秒後自動關上，記得快點走過去！
  4. 和紅石密碼鎖比一比：哪一個比較容易改密碼？
📌 聊天指令會留在聊天紀錄裡，別人往上翻就看得到密碼——真正的密碼要小心保管喔！
