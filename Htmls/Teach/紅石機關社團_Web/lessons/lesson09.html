第 9 堂 ／ 單元3　感測與自動化

觀察者：一有變化就通知 👀

觀察者有一張臉，一直盯著前面那一格。那一格只要有任何變化（長大、被放方塊、被挖掉、紅石開關），它就從背後送出一個很短的訊號。今天要做偵測警報和自動南瓜收割機！

🧱 觀察者、黏性活塞／活塞、南瓜種子、音符盒、紅石粉💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 知道觀察者「臉看前面、背後出電」，訊號很短（脈衝）。
  2. 分得出「一直有電」和「一下下的脈衝」。
  3. 做出自動南瓜收割機，並用 MakeCode 的「當方塊被破壞」做程式警報。

📚 新元件小教室

👀觀察者臉看著前面那一格；那一格有變化 → 背後的紅點亮一下，送出很短的訊號（脈衝）。
⚡脈衝只有一下下的訊號。觀察者、按鈕都會送出脈衝；拉桿是一直有電。

🔑 今天的重點

  • 放觀察者時，它的臉會朝向你。所以要站在「想偵測的東西」那一側放。
  • 南瓜收割機：觀察者看著南瓜莖（莖長出南瓜時會轉向），活塞推南瓜。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：自動南瓜收割機 🎃

🎒 準備物品：泥土、鋤頭、南瓜種子、觀察者、活塞、紅石粉、漏斗＋箱子（下堂課）

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 鋤一格耕地種南瓜種子，旁邊留一格泥土讓南瓜長。
  2. 在南瓜莖上方放觀察者，臉朝下看著莖。
  3. 在南瓜會長出來的那格上方放活塞（朝下），觀察者背後鋪紅石粉接到活塞。
  4. 用骨粉讓南瓜快點長：南瓜一長出來，活塞就把它打掉！
💡 觀察者看著「南瓜長出來的那一格」也可以，但活塞伸出去時會被觀察者看到又觸發一次，看著莖比較穩。
🐣 三、四年級：做出 1 組收割機。
🦊 五、六年級：做成 4 組並排，共用一條紅石線。

🎮 應用 2：挖礦偵測警報 ⛏️

🎒 準備物品：鑽石礦、觀察者、紅石粉、音符盒、紅石燈

🧱 在遊戲裡做

  1. 在牆上放一塊鑽石礦當「寶物」。
  2. 牆後面放觀察者，臉看著鑽石礦。
  3. 觀察者背後接紅石粉到音符盒和燈。
  4. 有人挖走鑽石礦 → 警報響一聲、燈閃一下！
💡 觀察者只送出很短的訊號，燈只會閃一下。想讓燈一直亮，要用第 13 堂的記憶電路。
🐣 三、四年級：做出挖礦警報。
🦊 五、六年級：連「放回去」也會響嗎？試試看並解釋為什麼。

💻 MakeCode：程式版挖礦警報

MakeCode 的「當方塊被破壞」就像程式裡的觀察者：一有事情發生就執行。比較兩種「偵測」的差別。

積木（積木上的文字可能因版本略有不同） 
blocks hat: 當 [鑽石礦] 被破壞
  player: 說 {"警報！有人在挖鑽石礦！"}
  gameplay: 時間設為 [夜晚]
blocks hat: 當 [鑽石礦] 被放置
  player: 說 {"鑽石放回去了，謝謝！"}
  gameplay: 時間設為 [白天]
JavaScript
blocks.onBlockBroken(DIAMOND_ORE, function () {
    player.say("警報！有人在挖鑽石礦！")
    gameplay.timeSet(gameplay.time(NIGHT))
})
blocks.onBlockPlaced(DIAMOND_ORE, function () {
    player.say("鑽石放回去了，謝謝！")
    gameplay.timeSet(gameplay.time(DAY))
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 拼好積木後，在附近放幾塊鑽石礦。
  2. 挖掉一塊：聊天室出現警報，天馬上變黑！
  3. 放回一塊鑽石礦：天又亮了。
  4. 比一比：觀察者只看「一格」，程式看「全世界的鑽石礦」。
📌 「當方塊被破壞」偵測的是任何地方的那種方塊；觀察者只盯著自己面前那一格。

👩‍🏫 教師備註
  • 南瓜生長很慢，課堂上請用骨粉加速；或把示範改成「甘蔗收割機」（觀察者看甘蔗第 3 格）。
  • 基岩版觀察者也會偵測到很多小變化（例如紅石粉強度改變），學生的電路若「莫名其妙一直觸發」，多半是觀察者看到了自己電路的變化。
  • 「當方塊被破壞」積木在 MakeCode 的「方塊」分類下。
