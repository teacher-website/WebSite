📖 課程簡介

本社團以雷射切割為主題，對象為國小三至六年級學生，共 20 次課程，每次兩節課。學生使用免費繪圖軟體 Inkscape 設計圖案，再透過 Flux Beambox 雷射切割機切割 3 mm 密集板。課程由淺入深：先認識雷射原理、機器構造並通過安全駕照考試，接著學習基本形狀、布林運算、文字、貝茲曲線與點陣圖描圖，製作平面吊飾與鑰匙圈；再學習量測、切縫與卡槽，完成十字插接造型與手機架；進而設計指接榫筆筒與有蓋寶物盒等立體作品。每堂課搭配互動教學網頁與設計產生器，任務分為三四年級與五六年級兩個層次。學期末學生自訂主題完成創客專題並舉辦成果展，培養空間概念、精準量測、設計思考與解決問題的能力。

每堂課網頁都有：今日目標、可計時的上課流程（40＋10＋40 分）、魔法小教室、互動實驗室、快捷鍵小卡、可打勾的任務步驟（🐣 三四年級／🦊 五六年級）、闖關測驗、老師備課提醒。

🦺 雷射教室安全守則

  1. 雷射切割時一定要有人看著，不可以離開。
  2. 切割前確認排風打開、蓋子關好；不可以打開蓋子看雷射光。
  3. 只切老師準備的材料（PVC、人造皮革、不明塑膠會產生有毒氣體）。
  4. 看到持續火焰：按暫停 → 叫老師 → 不要開蓋；滅火器在機器旁。
  5. 切完等 10 秒讓煙抽乾淨再開蓋，作品邊緣可能還熱。
  6. 有「雷射安全駕照」才可以在老師陪同下操作機器。

⏱️ 雷射切割機只有一台怎麼辦？

  • 小作品（吊飾、鑰匙圈）：老師把全班的檔案合併成一個 Beam Studio 檔一次切，省下換板、對焦時間。
  • 大作品（筆筒、寶物盒、專題）：當堂設計 → 課後由老師集中切割 → 下一堂組裝，所以第 15～16、17～18、19～20 堂兩兩成對。
  • 等待切割的學生：做互動實驗室、闖關測驗、上色組裝或幫同學檢查檔案。
  • 第 3 堂的「全班切割排隊計算機」可以先試算一堂課切不切得完。
