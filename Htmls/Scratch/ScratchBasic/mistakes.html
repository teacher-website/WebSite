上半部是症狀診斷表：學生說「我的程式怪怪的」時，從症狀往回找原因。

一、症狀診斷表（學生最常回報的狀況）

依「學生怎麼描述」排序，不是依積木類別。課堂巡桌時最好用。

學生說的症狀最可能的原因先檢查這裡
按了綠旗完全沒反應腳本最上面沒有事件積木最上面是不是「當 🏳 被點擊」？積木有沒有真的接在一起？
只動了一下就停了動作積木放在 C 型積木下面而不是裡面把積木拖進凹槽，看凹槽有沒有被撐開。
程式好像沒跑，角色沒動迴圈裡沒有「等待」，快到看不見在迴圈裡加「等待 0.2 秒」再跑一次。
角色亂飛、方向不對迴轉方式是「左﹣右」，只會翻面不會轉把迴轉方式設成「任意」再看方向。
角色卡在邊緣一直抖碰到邊緣後沒有轉身，下一圈又碰到「碰到邊緣就反彈」有沒有放在迴圈裡？
「如果」好像沒作用「如果」只檢查一次把「如果」整塊放進「重複無限次」裡面。
程式停不下來用了「重複無限次」次數確定的用「重複 N 次」，有結束條件的用「重複直到」。
「重複無限次」下面接不了積木它的形狀是平的，永遠輪不到下面改用「重複直到 條件」，做完才往下走。
迴圈一次都沒跑「重複直到」是先檢查再做，一開始條件就成立把條件唸出來：「重複直到 ___ 成立」現在成立嗎？
說話的字一閃就不見用了「說出…持續 N 秒」，時間太短要一直留著就用沒有「持續」的那一塊。
換造型看不出在走路沒有等待，或只有一個造型「換下一個造型 → 等待 0.2 秒」要成對出現。
角色不見了找不到用了「隱藏」，或幻影效果 100放一塊「顯示」＋「清除圖像效果」再跑。
圓形／六角形積木放不上去形狀不對，它們不是動作積木它們要放進別塊積木的欄位，不能單獨接在腳本上。
答對了卻說我答錯答案多一個空格，或用「＝」比對太嚴格先確認前後沒空格；想寬鬆一點改用「字串 ___ 包含 ___」。
第二次玩，限時挑戰馬上結束忘了「計時器重置」，計時接著上次累加綠旗下面第一塊放「計時器重置」。
「且」永遠不成立兩個六角形欄位有一格是空的兩邊都要放進布林積木才會運作。
數字算出來一長串小數隨機取數有一格填了小數，或除不盡兩格都填整數；或包一層「四捨五入數值」。
分數／位置記不住「詢問的答案」只有一格，會被新答案蓋掉需要保存的值要存進變數。
分數一直是 0 或 1「變數 ___ 設為 0」被放進迴圈裡，每圈都歸零歸零只放在綠旗下面，迴圈裡用「改變 1」。
分數扣不掉想減分卻用了正數「變數 ___ 改變 -1」，沒有另一塊減少積木。
清單拿不到東西把第一項當成第 0 項清單的第一項是 1；拿超過長度會回傳空白而不是報錯。
用迴圈刪清單卻刪錯刪掉一項之後，後面的編號會整個往前移從最後一項往前刪，或直接用「刪除所有項目」。
自訂積木按了沒反應只放了呼叫積木，沒有同名的「定義」同一段腳本裡要有「定義 ○○」，名字也要一樣。
