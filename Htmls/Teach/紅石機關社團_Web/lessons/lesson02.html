紅石火把：訊號反過來 🕯️

紅石火把會自己發電，但只要它「背後」的方塊有電，火把就會熄滅。這個「反過來」的魔法叫做 NOT（反相），是所有邏輯電路的基礎。

🧱 紅石火把、紅石方塊、石頭方塊、拉桿、紅石燈💻 MakeCode：搭配⏰ 40 分＋下課 10 分＋40 分

🎯 今日目標

  1. 知道紅石火把平常會發電，背後的方塊有電時會熄滅。
  2. 做出「拉桿關燈反而亮」的反向燈。
  3. 用 MakeCode 的聊天指令放紅石方塊，當作「遙控開關」。

📚 新元件小教室

🕯️紅石火把插在方塊側面或上面。平常會發電；它插著的那個方塊有電時就熄滅。
🟥紅石方塊整塊都是電源，永遠有電。可以被活塞推、也可以用程式放。
🪨石頭方塊紅石粉接到石頭時，石頭會「帶電」。

🔑 今天的重點

  • NOT（反相）：輸入有電 → 輸出沒電；輸入沒電 → 輸出有電。
  • 網頁模擬器裡，火把的「棍子」那一頭就是它的背後。

🖥️ 網頁模擬器是「從上往下看」的示意圖：先在這裡想清楚線路，正式結果以遊戲為準。操作：選工具 → 點格子放元件；同一種元件再點一次會轉方向；🖐️ 操作開關；🧽 清除。

🎮 應用 1：反向燈 🔄

🎒 準備物品：拉桿、紅石粉、石頭、紅石火把、紅石燈

🖥️ 先在網頁試試看

🧱 在遊戲裡做

  1. 地上放拉桿 → 紅石粉 → 石頭方塊。
  2. 在石頭的另一側面插一支紅石火把（對著石頭側面按右鍵）。
  3. 火把旁邊放紅石粉，接到紅石燈。
  4. 拉桿關著時燈亮，打開拉桿燈反而熄滅！
💡 火把要插在「被紅石粉接到的那顆石頭」上。插在地上的火把不會受影響。
🐣 三、四年級：做出反向燈，說說看「為什麼開了反而暗」。
🦊 五、六年級：網頁挑戰：用 2 支火把讓燈「反過來再反過來」，再到遊戲裡蓋出來。

🎮 應用 2：拿走寶石就熄燈 💎

🎒 準備物品：紅石方塊、紅石燈、紅石火把

🧱 在遊戲裡做

  1. 把紅石方塊放在紅石燈旁邊，燈馬上亮：紅石方塊本身就是電源。
  2. 在展示台上放一個紅石方塊當「寶石」，旁邊接燈。
  3. 把寶石挖走 → 燈就熄了。🦊 加一支火把，讓「寶石被拿走時」警示燈反而亮起來。
💡 紅石方塊不需要開關，放下去就一直有電。所以用程式「放」或「拿走」它，就等於開關。
🐣 三、四年級：做出寶石展示台。
🦊 五、六年級：寶石被拿走時警示燈會亮（要用到火把）。

💻 MakeCode：聊天指令遙控開關

程式不能直接扳拉桿，但可以「放一個紅石方塊」或「把它換成空氣」。這就是用程式控制紅石電路的方法，後面很多堂都會用到。

積木（積木上的文字可能因版本略有不同） 
player hat: 當聊天指令 {"on"}
  blocks: 放置 [紅石方塊] 位於 {~0 ~0 ~2}
player hat: 當聊天指令 {"off"}
  blocks: 放置 [空氣] 位於 {~0 ~0 ~2}
JavaScript
player.onChat("on", function () {
    blocks.place(REDSTONE_BLOCK, pos(0, 0, 2))
})
player.onChat("off", function () {
    blocks.place(AIR, pos(0, 0, 2))
})

在 MakeCode 上方切換到「JavaScript」，整段貼上，再切回「積木」就會變成上面的積木。

⬇️ 下載 MakeCode 檔（.mkcd） Minecraft Education 按 C → MakeCode → 匯入 → 選這個檔案，打開就是上面的積木，不用自己拼。

🧪 試試看

  1. 在反向燈的石頭旁邊留一格空位，旁邊放一個金磚當「站的位置」。
  2. 按 C 打開程式碼建立器，選 MakeCode，建立新專案，拼出上面的積木。
  3. 站在金磚上、面向空位，按 T 輸入 on：空位出現紅石方塊，反向燈熄滅。
  4. 輸入 off：紅石方塊消失，燈又亮了。
📌 ~0 ~0 ~2 是「從玩家站的位置往前 2 格」，所以要站在同一個地方、面向同一邊下指令。

👩‍🏫 教師備註
  • NOT 的生活例子：「下雨就不出去玩」「沒人在家時燈要關」。
  • MakeCode 需要在建立世界時開啟「作弊」(Cheats) 才能用程式碼建立器。
  • 學生常把火把插在地上而不是石頭上，請他們從火把的棍子看「它靠著誰」。
  • pos(0,0,2) 是相對座標；若學生站錯位置，紅石方塊會出現在別的地方，可以先用 ~0 ~0 ~2 放一顆金塊試位置。
